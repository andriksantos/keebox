    Why developers use KEEBOX LIST™¶

    • Curated, not scraped — every resource is chosen by developers and grouped by what you are trying to build.
    • Kept up to date — links are checked automatically every month; renamed projects are updated and dead ones removed.
    • Fast to search — press / anywhere to search all 80,000+ resources instantly.
    • Free and open source — no sign-up, no paywall. Anyone can contribute.

    Frequently asked questions¶

    What is KEEBOX LIST™?

    KEEBOX LIST™ is a free, open-source directory of curated software development resources. It groups 7,000+ tools, libraries, frameworks, courses and guides by topic — AI, data, Python, Go, Rust, Java, .NET, PHP, web and mobile development, APIs, cloud, DevOps, security, testing, design, game development, IoT and more — plus a section in Spanish — so developers can find reliable resources quickly.

    Is KEEBOX LIST™ free?

    Yes. The site is completely free, has no sign-up and its source is published on GitHub under the MIT license.

    How are resources selected and kept up to date?

    Resources are curated by developers and reviewed through pull requests. An automated job checks every link monthly; projects that move are updated to their new address and projects that disappear are removed.

    How can I suggest a resource?

    Open an issue or send a pull request following the contribution guide. One link per pull request, with a short description.

    Who maintains KEEBOX LIST™?

    KEEBOX LIST™ is created and maintained by Andrik Santos, with contributions from the developer community.
