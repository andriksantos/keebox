    Uno Platform¶

    Open-source .NET UI platform for building cross-platform apps.

    Source

    223 resources imported from MartinZikmund/awesome-uno-platform, dedicated to the public domain (CC0 / Unlicense). Thanks to its maintainers and contributors. Part of the KEEBOX Library · Category: Platforms.

    About this list¶

    Uno Platform lets .NET developers write a single C# and XAML codebase that runs on Windows, iOS, Android, macOS, Linux and the browser through WebAssembly. It is an alternative to .NET MAUI and Avalonia that reuses the WinUI API surface.

    This list gathers samples, libraries, tools and live apps built with Uno. If you are evaluating it, check Live apps and Open-source apps to see real production results, then use Samples and Libraries to start your own project.

    Repositories¶

    • Uno Platform - Main repository of Uno Platform, including the full API surface of UWP/WinUI, the best place to submit issues and contribute.
    • Uno Themes - Material and Cupertino theme library for Uno Platform apps. In addition, includes advanced controls based on Android/iOS developer guidelines.
    • Uno Toolkit - Multiplatform-first UI component library to speed up application development. Also provides Material and Cupertino styles for the included components.
    • Uno Gallery - Controls and API gallery app. Includes live examples of most built-in controls and features along with easy to use code snippets.
    • Uno Samples - A growing collection of code samples and snippets.
    • Uno Core - Provides a set of reusable utilities and helpers. Used by the main Uno Platform repository.
    • Uno UI Test - Xamarin.UITest-style UI testing, using Selenium for WebAssembly and Xamarin.UITest for Android and iOS.

    Tools¶

    IDE and Design¶

    • Uno Platform Extension for Visual Studio - Project templates, Hot Reload and Hot Design tooling for Visual Studio 2022 and 2026.
    • Uno Platform Extension for Visual Studio Code - Adds a range of productivity boosters to Visual Studio Code, including XAML IntelliSense, Hot Reload, and mobile target debugging support.
    • Uno Platform for Figma - Figma plugin that generates responsive XAML or C# Markup from high-fidelity designs.
    • Uno Material Toolkit - Figma file to use with the Figma plugin.
    • Uno Platform Studio - Productivity suite bundling Hot Reload, Hot Design, design-to-code, MCP servers and an AI agent, usable from any IDE or OS.
    • Hot Design - Agentic visual designer that turns the running app into an editable design surface, from Visual Studio, VS Code or Rider.
    • Hot Reload - Applies XAML and C# changes to the running app on every target without rebuilding, free in the Community tier.
    • Uno Platform Plugin for JetBrains Rider - Rider plugin adding project templates, Hot Reload and Hot Design support.
    • DevToolsUno - In-app diagnostics for inspecting the live visual tree, bindings, resources, styles, events and memory.
    • XAML Styler - XAML formatter for Visual Studio, Rider and the command line, used to enforce markup style in the official repositories.

    AI¶

    • Uno Platform MCP - Free remote MCP server that grounds AI agents in the current documentation and API references.
    • Uno App MCP - Local MCP server that lets AI agents inspect and drive a running app through its visual tree, properties, clicks, typing and screenshots.
    • Uno Platform Studio Agent Plugin - Agent plugin with an app-building agent, topic skills (MVUX, navigation, Toolkit, themes, testing) and Hot Reload hooks for Claude Code, GitHub Copilot and Codex.
    • Uno Platform Studio App - Browser-based AI app builder (Pro) that generates a project from a prompt, previews it live and exports it to your IDE.
    • dotnet-agentic-engineering (dna) - Agent directives, skills and tooling that detect a repo's stack (MVUX or MVVM, C# Markup, design system, SDK version) and install a matching skill set.
    • Uno Platform Skills - Claude Code skills covering MVUX, navigation, Toolkit, Material theming, C# Markup, WebAssembly and WPF migration.
    • Uno DevServer CLI - Dev Server CLI that registers the MCPs with AI agents, diagnoses the environment and drives a running app from scripts or CI.

    Build and Deployment¶

    • Uno.Check - CLI that checks and installs the SDKs, workloads and tooling needed for each target platform.
    • Uno.Templates and Uno.Sdk - The dotnet new app and library templates plus the single-project MSBuild SDK they build on.
    • Uno.Wasm.Bootstrap - MSBuild package that builds and hosts .NET code in the browser via WebAssembly, with AOT and PWA support.
    • Uno.XamlMerge.Task - MSBuild task that merges a control library's resource dictionaries into a single file for faster resource lookup.
    • DependencyPropertyGenerator - Source generator for dependency properties, routed events and weak events, with automatic Uno detection.
    • Velopack - Installer and auto-update framework for desktop apps, with an official Uno sample and setup guide.
    • Uno.Resizetizer - Build-time generation of app icons, splash screens and scaled images from SVG or PNG sources.

    Testing¶

    • Uno.UI.RuntimeTests.Engine - In-app MSTest runner for UI tests on devices, desktop and the browser, with NUnit reports and CI sharding.

    • DesktopFlyouts - Desktop flyouts shown from tray icons or programmatically, including on Linux with X11.

    Graphics¶

    • SkiaSharp - Cross-platform 2D graphics API based on Google's Skia, with XAML canvas views.
    • Svg.Skia - SVG rendering library with animated SVG controls and inline SVG authoring in XAML.
    • ProGPU - WebGPU-based rendering, composition, vector and text engine with an embeddable host control.
    • Zenith.NET - GPU graphics and compute abstraction over DirectX 12, Metal and Vulkan, with a rendering view control.
    • Ab4d.SharpEngine - Commercial cross-platform 3D rendering engine built on Vulkan, free for non-commercial open-source projects.
    • SKCanvasElement - Hardware-accelerated SkiaSharp drawing hosted directly in the XAML visual tree.
    • GLCanvasElement - OpenGL rendering through Silk.NET inside the XAML visual tree, with WebGL on WebAssembly.
    • Lottie Animations - Built-in Lottie playback through AnimatedVisualPlayer, rendered with Skottie or a managed engine.

    • Microsoft MVVM Toolkit - Modern, fast, and modular MVVM library.

    • ReactiveUI.Uno - ReactiveUI integration with view bases, activation, routing, bindings and schedulers.
    • R3 - Modern reimplementation of Reactive Extensions, with an extension package for dispatcher-timer and rendering-frame providers.
    • Singulink UI Toolkit - Strongly typed, deep-linkable MVVM navigation plus a task runner, XAML helpers and trimmed Fluent icon packs.
