    Apps¶

    Mapping¶

    • OnlineWardleyMaps - Online open source mapping tool. For updates follow @MapsAsCode on Twitter. Hosted version available here. Online documentation Wardley Maps as Code.
    • Wardley Maps for Visual Studio Code - Render and edit Wardley maps within Visual Studio Code. This VSCode extention leverages the engine from OnlineWardleyMaps.com. Online documentation Wardley Maps as Code.
    • Wardley Maps for Obsidian.md - Render and edit Wardley maps within Obsidian.md. This community plugin leverages the engine from OnlineWardleyMaps.com. Online documentation Wardley Maps as Code.
    • Wardley Maps for Jupyter Notebooks (ipywardley) - A plugin for generating Wardley maps in Jupyter Notebooks.
    • MapScript - Note MapScript is built on Observable. Read their Terms of Service. MapScript feature requests. Hosted version available here.
    • Go-Wardley - Generates a Wardley map in SVG format from a HCL-based map description file.
    • Mapkeep - Multiplayer Wardley Maps at a click of a button. Collaborate on your maps with others. Host your maps for free. For updates, you can follow @mapkeep on Mastodon, @mapkeep on X, mapkeep on LinkedIn, subscribe to the YouTube Channel, or subscribe to the News and Updates blog.
    • Glamorous Toolkit - A moldable and programmable environment in which Wardley Maps can be intertwinned with knowledge management and multi language notebooks. Follow @feenkcom to learn more.
    • Excalidraw - Online diagram tool creates quick and easy, handdrawn diagrams and maps. keyboard shortcut '0', browse libraries and Add the "Wardley Maps Symbols" lib.
    • Flowchart fun - text based tool to generate quick flowcharts. Excellent way to quickly create a Value Chain - very useful in conversation or during a meeting.
    • wardleyToGo is a SDK to do map-as-code and a high level language (wtg) to express map-as-data. The set of tools allows an easy integration of the map in CI, and the online demo allows to desing maps online.
    • Map - Native macOS app to build wardley maps using its own wmap syntax (Apple Silicon only). GPLv3. It includes a QuickLook plugin to preview wmap files as images, and sharing to collaboratively edit maps.
    • Map for Linux - GTK4 Linux app to build wardley maps using the wmap syntax. AGPLv3.
    • wmap - A command line tool to render wmap formatted maps to PNG or SVG.

    Doctrine Assessement¶

    • Doctrine - A simple tool for visualising how competitive a company is in light of Wardley's doctrine. Hosted version available here.

    Development¶

    • Join the Wardley AI Development Group on X/Twitter
    • An Exploration into Wardley Mapping Language Code - Create your own Wardley Mapping code editor in two easy steps.
    • Convert WM format to Many - A simple streamlit app to convert the OnlineWardleyMaps OWM format to JSON, TOML, JSON Graph and Cypher text.
    • cli-owm - Command-line tool that renders OnlineWardleyMaps DSL text to SVG. Pipes stdin to stdout, ships as npm package and standalone binaries. Uses the OnlineWardleyMaps parser.
    • Exploring Prompt Engineering using Wardley Maps - A series of blog posts about AI, Python and Wardley Mapping.
    • wiki-plugin-wmap - A plugin for fedwiki that enables you to write maps in wmap syntax and create links to other wiki pages from components.
    • tree-sitter-wmap - A wmap syntax parser using tree sitter with a bundled neovim plugin that provides syntax highlighting.
    • wmap-parser-swift - A Library for Swift that parses wardley maps using wmap syntax for macOS and iOS development.
    • wmap-parser-js - A pure javascript parser for wardley maps using wmap syntax that can run on the browser or node.
    • wmap-parser-rust - A rust parser for wardley maps using wmap syntax.
    • wmap-parser-c - A high performance ANSI C parser for wardley maps using wmap syntax.
    • wmap-renderer-canvas - A javascript renderer that creates maps in a canvas element for wardley maps that use the wmap syntax, can be used exclusively on the browser or on nodeJS.
    • wmap-renderer-svg - A browser only renderer that creates SVGs for wardley maps that use the wmap syntax.
    • wmap-renderer-rust A rust renderer that generates cairo surfaces, SVGs and PNGs for wardley maps that use the wmap syntax.
