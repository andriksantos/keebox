    CCU Alternatives¶

    • debmatic - Install the Homematic OCCU on Debian based amd64, armhf and arm64 systems (Debian, Ubuntu, Raspbian, Armbian)
    • OpenCCU - Lightweight, OCCU and Linux/buildroot-based distribution for running a HomeMatic CCU on embedded devices like the RaspberryPi, x86/ARM or as virtual appliance (formerly known as RaspberryMatic).
    • openccu-lite - Fork of OpenCCU: Homematic CCU firmware without ReGaHSS and with new web interface.
    • piVCCU - Install the original Homematic CCU firmware inside a virtualized container (lxc) on Raspbian or Armbian.

    CCU Addons¶

    • CCU Historian - Langzeit Archiv und Graphen.
    • ccu-addon-battery - Statistiken über den Batterieverbrauch von Homematic Geräten
    • ccu-addon-longpressdim - Dimmen mit langen Tastendruck über Schnittstellen- und Systemgrenzen hinweg.
    • ccu-addon-mui - Moderne, responsive Progressive Web App (PWA) für die CCU3 mit integriertem WebSocket-Server.
    • CUxD - Der "Leatherman" für die CCU. Verbindet FS20, ... (💵 EnOcean, ...), stellt virtuelle Geräte und hilfreiche Tools zur Verfügung.
    • CUxD-Highcharts - Visualisiert CUxD DEVLOGS mit Highcharts/Highstock (verwaist, Maintainer gesucht).
    • Email - HomeMatic CCU Addon für den Email Versand.
    • hm2mqtt.js - Connect CCU to MQTT, Home Assistant auto discovery, follows mqtt-smarthome convention
    • hm-influxdb2 - Addon for the CCU3/OpenCCU to log data from devices into an InfluxDB2.
    • hm-print - CCU Programme drucken.
    • hm-sonos - HomeMatic CCU Addon zur Steuerung von Sonos Playern.
    • hm-tools - Sammlung von Tools für OpenCCU.
    • hm_pdetect - Anwesenheitserkennung über die FRITZ!-Box
    • Homematic-addon-hue - HomeMatic Addon für Philips Hue (archiviert).
    • homematic_check_mk - Addon for the Homematic CCU2 or an OpenCCU device which acts as an check_mk_agent.
    • homematic-node-exporter - Prometheus Node Exporter packaged as Addon for the Homematic CCU3 and OpenCCU.
    • HQ-WebUI - Schnelles alternatives WebUI für die Homematic CCU mit Skript-Editor (verwaist, Maintainer gesucht).
    • JP-HB-Devices-addon - Addon das über 80 Selbstbau-Geräte (AskSinPP HomeBrew) in die CCU/OpenCCU Firmware integriert.
    • jq - jq packaged as Addon for the Homematic CCU3.
    • Mosquitto - Mosquitto packaged as Addon for the Homematic CCU3 and OpenCCU
    • Patcher - CCU3 Addon zur komfortablen Anwendung von Patches.
    • Redis - Redis packaged as Addon for the Homematic CCU3 and OpenCCU
    • RedMatic - Node-RED als Addon für die Homematic CCU3 und OpenCCU. Liefert u.A. komfortable HomeKit-Integration und spezielle Nodes zur Anbindung der CCU an MQTT mit.
    • ScriptParser - Addon zur Syntaxprüfung von HomeMatic Skripten.
    • WebMatic - Alternative, für Mobilgeräte optimierte Bedienoberfläche, läuft direkt auf der CCU.
    • XML-API - Vereinfachter CCU Zugriff via HTTP/XML.

    Interfacing Software¶

    • CCU-AI-MCP - MCP-Server für OpenCCU/CCU, gibt KI-Assistenten (LLMs) über konfigurierbare HM-Skripte Zugriff auf das Smart Home.
    • CCU-Jack - CCU-Jack bietet einen einfachen und sicheren REST-basierten Zugriff auf die CCU, auch als Addon verfügbar.
    • ccu-mcp - MCP server enabling AI assistants to control Homematic devices via the CCU's JSON-RPC API, no addon required.
    • homebridge-homematic - Homebridge Plugin zur Einbindung von Homematic Geräten in HomeKit.
    • homebridge-homematicip - Homebridge Plugin zur Einbindung von Homematic IP mit HmIP-HAP via Cloud.
    • homematicip-hcu - Home Assistant Integration zur lokalen Anbindung der Homematic IP Home Control Unit (HCU) ohne Cloud.
    • homematicip_local - Home Assistant Custom Component zur lokalen Anbindung von CCU/OpenCCU (Homematic und Homematic IP), basiert auf aiohomematic.
    • matterbridge-homematic - Matterbridge Plugin to bridge a Homematic CCU's devices to the Matter ecosystem.
    • node-red-contrib-ccu - Node-RED Nodes for the Homematic CCU.
    • OpenCCU-Loom - Standalone Go daemon bridging Homematic / Homematic IP CCUs to MQTT (with Home Assistant Discovery), REST + WebSocket, an MCP server and a native Matter bridge.
    • RedMatic-HomeKit - HAP-Nodejs basierte Node-RED Nodes um (Homematic-)Geräte in HomeKit einzubinden.
    • RedMatic-Matter - Matter.js basierte Node-RED Nodes, die Homematic-Geräte und beliebige Node-RED-Daten als Matter-Bridge bereitstellen.

    Misc Software¶

    • check_homematic - Nagios/Icinga Plugin for checking Homematic CCU.
    • godevccu - Virtual HomeMatic CCU with XML-RPC and JSON-RPC servers written in Go, single static binary for testing integrations.
    • hm-buildroot - Buildroot environments / cross compiler toolchains to build native applications for the CCU and OpenCCU.
    • HM-Explorer - Electron based helper app for the Homematic CCU (macOS/Windows).
    • hm-simulator - Simulates (partly) a Homematic CCU.
    • hmcfgusb - Utilities to use the HM-CFG-USB(2) on Linux/Unix.
    • HMDeviceFirmware - Archive of current and past firmware update files for HomeMatic and Homematic IP devices.
    • hmGetInfo - Collect paramsets and paramsetDescriptions from your Homematic CCU as JSON.
    • HMScriptEditor - A very simple macOS editor and runner for HomeMatic ("Rega") scripts.
    • HomeHub - PHP/XML-API basiertes Webfrontend. Forum
    • Homematic Script Language - Visual Studio Code extension providing syntax highlighting for HomeMatic Script (.hms) files.
    • homematic-manager - Manage homematic interface processes (rfd/hs485d/homegear).
    • language-homematic - Adds syntax highlighting and snippets to HomeMatic Script files in Atom.
    • pydevccu - Virtual HomeMatic CCU XML-RPC and JSON-RPC server with fake devices for development and testing.
    • ReGaHss-Test - Automated System Tests of ReGaHss - the HomeMatic (O)CCU "Logic Layer" (formerly occu-test).

    Software Modules¶

    • aiohomematic - Python 3 interface to interact with Homematic devices via XML-RPC and JSON-RPC, successor of pyhomematic and base of homematicip_local.
    • binrpc - Xmlrpc_bin protocol client and server Node.js module.
    • go-hmccu - Go library for interfacing the CCU.
    • hm-discover - Node.js module to discover Homematic CCUs and interfaces.
    • Homematic IP Connect API - Official WebSocket API and example plugins (Java, Node.js) for developing plugins for the Homematic IP Home Control Unit (HCU).
    • homematic-gqls - A GraphQL service to query Homematic IP components based on homematicip-rest-api.
    • homematic-rega - Node.js Homematic CCU ReGaHSS Remote Script Interface.
    • homematic-xmlrpc - Xmlrpc client and server Node.js module.
    • homematicip-rest-api - Python wrapper for the homematicIP REST API (Cloud / Access Point Based).
    • occulite-client - Typescript client for openccu-lite.
    • openccu-loom-client - Async Python REST + WebSocket client for the OpenCCU-Loom daemon.
    • pmatic - Python API for Homematic. Easy to use.
