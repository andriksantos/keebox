    Web Performance Budget — techniques to ensure certain performance metrics for a website. This page brings together 65 links about Web Performance Budget, grouped into 2 sections. The largest sections are Learn, Tools, a good place to start if you are exploring the topic for the first time.     Tools¶

    Build and CI Tools¶

    • Lighthouse Budgets - Set a performance budget with Lighthouse and automate it with Lighthouse Bot.
    • webpack Performance Hints - Built-in webpack warnings or errors when assets exceed size limits.
    • Size Limit - Calculate the real cost to run your JS app or library and fail the pull request if it exceeds the limit.
    • bundlesize - Keep your bundle size in check.
    • size-plugin - Track compressed webpack asset sizes over time.
    • pr-bot - Compare your base branch with a pull request and report size differences.
    • rollup-plugin-size-snapshot - Track Rollup bundle sizes and treeshakability.
    • grunt-perfbudget - Grunt task for performance budgeting with WebPageTest.
    • pwmetrics - CLI for collecting Lighthouse metrics and asserting budgets (no longer maintained).
    • Import Cost - VS Code extension that shows the size of imported packages inline.

    Measurement Tools¶

    • Performance Budget Calculator - Calculate a performance budget for your site.
    • WebPageTest - Run lab tests from real browsers, devices and locations.
    • SpeedCurve - Synthetic and real-user monitoring with budget alerts.
    • sitespeed.io - Open source toolset to monitor and measure your site's performance.
    • Yellow Lab Tools - Online test to help speed up heavy web pages.
    • lightest - Visualize your web performance against competitors.
    • Perf Track - Track framework performance at scale.

    Monitoring¶

    • Perfume.js - Tiny web performance monitoring library that reports field data to your analytics tool.
    • Falco - Open source dashboard to monitor, analyze and optimize your websites.

    Bundle Analyzers¶

    • Bundlephobia - Find the cost of adding an npm package to your bundle.
    • webpack-bundle-analyzer - Visualize webpack bundle contents as an interactive, zoomable treemap.
    • Rollup Visualizer - Visualize and analyze your Rollup bundle to see which modules take up space.
    • bundle-buddy - Find source code duplication across your JavaScript chunks.
    • Parcel Bundle Visualiser - Parcel plugin to visualise bundle contents.
    • Disc - Visualise the module tree of Browserify bundles and track down bloat.
    • lasso-analyzer - Analyze and visualise bundles created by Lasso.
    • analyze-css - CSS selector complexity and performance analyzer.

    Website Analyzers¶

    • Lighthouse Metrics - Run Lighthouse tests from multiple locations at once.
    • dxsrc Site Check - Test your website in more than 90 tools (web-based and free).
    • PageGuard - Free website health scanner that measures Core Web Vitals and suggests action plans. No signup required.
    • Screpy - Track Core Web Vitals and page-speed changes across monitored pages.
    • Betterloop - Free website checker that ranks fixes and shows mobile and desktop PageSpeed Insights results. No signup required.
