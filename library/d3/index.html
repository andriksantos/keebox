    D3¶

    Library for producing dynamic, interactive data visualizations.

    Source

    145 resources imported from wbkd/awesome-d3, dedicated to the public domain (CC0 / Unlicense). Thanks to its maintainers and contributors. Part of the KEEBOX Library · Category: Front-End Development.

    About this list¶

    D3.js is the JavaScript library behind many of the most original data visualizations on the web. Instead of fixed chart types, it binds data to SVG, Canvas or HTML elements so you can design exactly the graphic you need.

    This list gathers chart libraries built on D3, mapping tools, utilities, server-side rendering and example galleries. If you only need standard charts, a higher-level library from Charts will be faster; use D3 directly when you need full control.
