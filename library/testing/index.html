    Software¶

    API Testing¶

    • API Spector - Open-source API clien, mock server and contract testing tool. Zero telemetry.
    • Bruno - Open-source API client for exploring and testing APIs.
    • API Status Check - Real-time status monitoring dashboard for 188+ third-party APIs (OpenAI, Stripe, AWS, GitHub, etc.) with response time tracking and free alert tiers.
    • Polarity - The First AI QA Engineer that does full E2E, API, UI testing. Understands your entire codebase and ensures all relevant tests are conducted with our long running agent setup.
    • BitDive - Zero-code API testing platform for Java/Kotlin. Captures deep runtime context (HTTP, SQL, methods), auto-generates mocks from real traffic, and enables Live Context Replay for E2E testing and debugging.
    • CORS Tester - A tool for developers and API testers to check if an API is CORS-enabled for a given domain and identify gaps.
    • HttpMaster - Professional software tool for HTTP testing and debugging.
    • Keploy - API Testing Platform that automatically generates unit test cases along with dependency mocks.
    • RestQA - REST API testing framework based on Gherkin.
    • SpecTest - Truly declarative API testing framework in Js, or plain JSON.
    • Tests Coverage Tool - Ultimate tool to measure gRPC service coverage from tests.
    • Swagger Coverage Tool - The Swagger Coverage Tool is designed to measure API test coverage based on Swagger documentation. It provides automated tracking and reporting of test coverage for APIs, helping ensure that your endpoints and services are well-tested.
    • Webhook Debugger & Logger - Enterprise-grade tool for testing, debugging, and logging incoming webhooks in real-time.
    • Webhook Debugger - Open-source, self-hosted webhook inspector with signature verification support.
    • Openhook - Open-source webhook inbox for capturing callbacks and inspecting request headers and bodies through a browser, REST API, or MCP.
    • Spiderhash - Webhook debugging and request inspection tool for testing callback payloads, headers, and delivery behavior.
    • KushoAI - AI-native platform for API contract testing, end-to-end testing, UI testing, and continuous security scanning, with self-healing tests that automatically adapt to code changes in CI/CD.
    • postman2pytest - Convert a Postman Collection v2.1 JSON file into a ready-to-run pytest test suite.
    • funapi - A free mock REST API service designed for practicing API testing, automation, and integration with realistic scenarios and endpoints.
    • SolidPing - Open-source (AGPL-3.0) uptime and API monitoring with a free hosted tier. Runs HTTP, gRPC, WebSocket and custom JS checks on a schedule and alerts when an endpoint fails.
    • BestJSON JSON Diff - Free browser tool for comparing saved JSON API responses by structure, with explicit array-order and record-ID matching rules.
    • Kerno - The AI Backend Runtime QA Engineer. Runs locally inside your coding agent's loop through MCP and tests each change against your running app and its real databases, queues and services.
    • OpenAPI Breaking Change Checker - Free browser tool that compares two Swagger 2.0 or OpenAPI 3.0/3.1 descriptions (JSON or YAML) and sorts each change into likely breaking, review-needed or compatible; the files stay in the browser.
    • Bifurc - Local-first API client, mock server and traffic proxy for macOS, Windows and Linux, with a CLI for CI.

    Security Testing¶

    • BeEF - Manipulate the browser by exploiting any XSS vulnerabilities you find.
    • OWASP ZAP - Intercepting proxy for HTTP traffic manipulation, security scanning, and exploitation.
    • BurpSuite - Intercept API and Reply with changes in realtime with according api manipulations.
    • Nuclei Scanner - nuclei is automated scanner for common vulnerability finding on site.
    • Darkmoon - Open-source (GPLv3) autonomous AI penetration-testing CLI with 50 specialist agents and 140+ offensive tools over MCP for DAST-style web and API security assessment.
    • appfuzz - Fuzzes WebAssembly apps against a simulated backend and reports crashes, injection, n+1 queries and data leaks, with an exit code for CI.

    AI & LLM Testing¶

    • promptfoo - Open-source framework for testing and red teaming LLM applications. Compare prompts, test RAG architectures, run multi-turn adversarial attacks, and catch security vulnerabilities with CI/CD integration.
    • voicetest - Open-source test harness for voice AI agents supporting Retell, VAPI, LiveKit, and Bland with autonomous simulations and LLM-based evaluation.
    • AgentSkeptic - Verifies AI/agent workflows by checking database state after execution, comparing expected vs observed outcomes with read-only SQL.
    • Evaliphy - Test your AI system end-to-end with Evaliphy. It uses a Playwright-style testing approach and generates HTML reports.
    • QASkills.sh - Open registry of 400+ QA and testing skills (Playwright, API, LLM evaluation, accessibility, performance) that AI coding agents install and follow via the qaskills CLI. Works with Claude Code, Cursor, and 30+ other agents.
    • nika - Workflow engine for AI with testing built in: nika test pins a workflow's offline behavior as a golden snapshot (deterministic mock provider, zero keys) and replays it in CI; every run also leaves a hash-chained trace for post-hoc verification.
    • crilio - An open-source Python CLI that uses LLM-as-a-Judge to automate semantic regression testing for LLM prompts in CI/CD, blocking GitHub PRs that cause hallucinations or break formatting rules. Supports OpenAI, Anthropic, and local Ollama models.
    • geokit-cli - Open-source CLI for automated AI search engine readiness testing, /llms.txt validation, and crawler access audits.
    • aiexpect - Python assertions for non-deterministic AI text that drop into pytest. Semantic and rule checks work offline; optional LLM judge with your own model; produces a Trust Score and a single-file HTML report.
    • OrcaReplay - Records a coding-agent session below the harness, keeping the verbatim request and response bytes, then replays the same run offline with the network off or forks it from a checkpoint onto other models with a verify command deciding the verdict.
    • flight-recorder - Record every nondeterministic input your code reads (LLM answers, HTTP, database, clock, randomness) as one JSONL tape per request, then replay the tape against the real code offline, bit for bit, with the first divergence named. Open format with Python, Node, .NET, Go, Java and PHP implementations.
    • OrcaPromptVault - Dated archive of the system prompts and tool-call schemas shipped AI agents send, so tests can be written against a product's real declared tool surface rather than a guess at it.
    • fanout-check - Offline Python library and CLI that checks observed concurrency, overlap, and launch timing in explicitly grouped tool or agent calls.
    • llmdrill - Open-source CLI that runs your app behind a local fake of the Anthropic and OpenAI APIs, injects outages (529/503 overloads, 429 with retry-after, hangs, cut streams) and grades its retries, backoff, timeouts and failover.
    • evalship - GitHub App that finds flaws in your LLM evals, says on every pull request which evals a change broke and why, and finds prompt and model changes that win beyond chance.
    • ScopeHaven - Runs an AI agent's tasks against a local copy of your app, as different users, and checks whether "done" matches what the app's records show. Node CLI and GitHub Action, Apache-2.0.
    • Bite - Open-source CLI that checks whether recent "fixed" commits are really guarded by tests: it takes each fix back out and runs the project's own tests to see if any fail. Free mode needs no API key.
    • judge-check - Checks whether an LLM judge can tell good output from bad by mixing planted decoys and known-good answers into its real inputs, then reporting how often the decoys pass. Zero dependencies, with an offline demo.
    • agentest - Open-source CLI that runs 130 deterministic checks on recorded OpenTelemetry GenAI traces, A2A agent cards and MCP tool lists, offline and without an LLM judge, and exports JUnit or SARIF for CI.

    Service Virtualization¶

    • Beeceptor - Easy to use no-code mock servers for service virtualization. Rest, SOAP, GraphQL supported. Create an API mock server from OpenAPI Specification or Postman collection.
    • Buggregator - Local debugging server with a mock server (OpenAPI import), HTTP request capture and a fake SMTP server whose API waits for an email and extracts one-time codes.
    • DeepfakeHTTP - Web server using HTTP dumps as a response source for API simulation.
    • fakecloud - Free, open-source local AWS cloud emulator for integration tests, with 23 services at 100% conformance and first-party test-assertion SDKs in 6 languages.
    • ghostwire - Open-source Linux tool that mocks ping, TCP connections, UDP errors and DNS per target address, with delay, jitter, loss and faults controllable live through an HTTP API; no proxy to point your program at, no root needed under exec.
    • mockd - Open-source multi-protocol mock server supporting HTTP, gRPC, GraphQL, WebSocket, MQTT, and SOAP with chaos engineering and proxy recording.
    • MockForge - Open-source API mock server written in Rust for HTTP/OpenAPI, gRPC, GraphQL, WebSocket, Kafka, MQTT and AMQP, with data generation and latency/fault injection.
    • MockServer - Mocking, debugging proxy and chaos engineering tool for multiple protocols (HTTP, gRPC, GraphQL, LLM, MCP, Kafka, TCP and more); mock any dependency, record/replay and inspect traffic, verify requests, and inject faults. Docker, JAR, Helm, multi-language clients.
    • WireMock - Open source HTTP mock engine written in Java. Embed in your test code, run as a standalone process, or deploy via Docker.
    • ApiNotes - Drop your OpenAPI spec and get a fully functional mock API server instantly. Export to Bruno API client or test directly.
    • Twinbay - Hosted, stateful twins of third-party APIs such as Shopify, Slack, Zendesk and QuickBooks for integration and AI agent tests. Each test run gets a private URL, and directives force states like rate limits or failed payments.
    • fieldtwin - Open-source, local, stateful twins of the Jobber and QuickBooks Online APIs for integration and AI agent tests, with checkpoints, rewind, and faults on demand.
    • OutageFence - Local HTTP fault-injection CLI by Slanta Cause that checks synthetic sensitive data against declared destination rules, with positive controls and offline reports.
    • atrezzo - Claude Code plugin that serves API mocks as deterministic projections of one seeded data set and checks the rendered DOM against a YAML scenario.
    • ChronoStack - Open-source CLI that moves time forward across a Docker Compose stack (Postgres, Redis and your services together, no code changes) to test trials, renewals, scheduled jobs and outages in virtual time, with scenarios, seeded simulated users and JUnit reports.

    Visual Testing¶

    • Fluxguard - Screenshot pixel and DOM change comparisons.
    • GoodLooks - AI-powered visual validation for Playwright tests.
    • Happo - Cross-browser screenshot and visual regression testing service, integrates with tools like Storybook, Playwright, and Cypress.
    • Image Diff - Free, browser-based pixel diff tool for comparing two images and highlighting exactly what changed, with an adjustable sensitivity threshold. No upload, no sign-up.
    • Lastest - Visual regression testing for Playwright with AI flake triage and baseline review.
    • TestingBot - Supports automated, manual, and visual testing.
    • recheck-web - Change comparison tool with Golden Masters and "unbreakable Selenium" tests.
    • Sherlo - Visual testing platform for React Native Storybook. Captures screenshots on iOS and Android simulators in the cloud and detects visual changes automatically.
    • wopee.io - Autonomous visual regression testing platform.
    • SmartUI by TestMu AI (formerly LambdaTest)- AI-Native Visual Testing Tool for Flawless UIs across browsers, apps, websites, and PDFs.
    • CurlShot - Screenshot API for capturing baseline and comparison images of web pages in CI as PNG, JPEG, WebP or PDF, with full-page and CSS-selector element capture, device presets and ad/cookie-banner blocking. Free plan available.
    • cloneproof - Scores how closely a website clone matches the original (pixels, layout, style, scroll motion) with Playwright and lists the exact differences.

    UI & End-to-End Testing¶

    • Polarity - Full visual and desktop environments showcasing complete E2E testing for all UI/UX features. Generated you Playwright, Cypress, and other code for you as the test runs.
    • ai-wright - Open-source library that adds AI action, assertion, and data extraction steps to Playwright tests, using annotated screenshots and your own OpenAI, Gemini, or Claude API key.
    • AnalyticsProof - Regression tests for analytics tracking: replays recorded website journeys and reports which step lost a dataLayer event or GA4 parameter. Has a free plan.
    • blastproof - Open-source AI agent that runs plain-English e2e tests in a real browser. It reads the pull request diff, runs only the tests for the pages that changed and can block the merge on a score. Runs locally or in CI with your own LLM key.
    • Browser Use - Open-source (MIT) Python AI agent that runs plain-English tasks in a real browser. Browser Use Cloud adds hosted stealth Chromium you can drive over CDP from Playwright, Puppeteer or Selenium, with session recordings and live view.
    • BugBug - No-code test automation tool for web applications.
    • cloudf.one - Rent a real Samsung Android phone in Singapore on a Singtel or M1 SIM and use it from a browser tab, to check how an app behaves for Singapore users. Manual use only, no Appium or scripts.
    • Clousd - Cloud Android phones (150+ device models, Android 12-17) for app testing in a browser tab, over ADB, or through a REST API and MCP server for AI-driven tests.
    • ContextQA MCP - Hosted MCP server for creating and running end-to-end tests and investigating failures, with OAuth browser sign-in.
    • Courgette - Declarative BDD UI testing with Gherkin.
    • DevAssure - Agentic testing for E2E web UI on real browsers. Agent can be added to GitHub Actions to test only the flows that have changed in a PR.
    • Device Hub Pro - Free, open-source macOS app for manual testing on Android emulators, Android phones and iOS simulators side by side, with live mirroring, device controls (network, location, permissions, deep links, push), logs, screenshots and screen recordings.
    • DeviceLab - Private device lab infrastructure for mobile testing. Connect your own iOS/Android devices and run Appium, Maestro, or XCUITest remotely via WebRTC. Zero-trust architecture keeps test data on your network.
    • Drengr - Mobile tests written as plain-English tasks instead of selectors, driven by an agent on real Android devices and iOS simulators. Works where there is no accessibility tree — canvas, games, Flutter without semantics labels — by falling back to vision and coordinates. Runs locally or in CI; bring your own model key.
    • Drengr Runner - Drive an iOS simulator over HTTP from any language. A 479-line Swift XCTest target replacing WebDriverAgent on simulators. Apache-2.0.
    • e2e - Open-source end-to-end testing framework for web and mobile apps, combining natural-language agent actions with locators and assertions.
    • Ferrum - Chrome automation via CDP with a high-level Ruby API.
    • flutter-skill - AI-powered E2E testing via MCP for Flutter, React Native, iOS, Android, Electron, Tauri, KMP, and .NET MAUI. Zero test code.
    • GenClass - Open-source browser library that reports race conditions in a web app while they happen (stale responses written over newer data, duplicate submits, failure storms) with a small on-device model. Its local MCP server re-runs a page with responses delivered in different orders to find races and replays one order to prove a fix.
    • Hyperbrowser - Scalable headless browser testing with built-in session recording.
    • Hercules - Open-source end-to-end testing agent.
    • Kane CLI - Natural-language browser testing from the terminal, locally or in CI, with export to Playwright and shareable run evidence.
    • Keploy – Open-source AI-powered end-to-end testing tool for APIs and microservices that auto-generates test cases and mocks from real traffic.
    • mendwright - Self-healing selectors for Playwright and Selenium in Python. Repairs a broken selector from a saved fingerprint of the element, asks a model only when that isn't enough, checks the repair on the live page and can write it back into your code.
    • Mockatoo - Free hosted mock OAuth provider for Google, GitHub, Microsoft, Apple and four other providers, so E2E tests in Playwright, Cypress or CI can sign in without real accounts, CAPTCHAs or app registration.
    • Momentic - End-to-end tests for web apps in Chromium and mobile apps on hosted iOS simulators and Android emulators, written as YAML that mixes preset steps with natural-language AI steps and run from a CLI locally or in CI. Includes Mo, an agent that explores a running app from a brief and reports findings with evidence.
    • Proxy QA Browser - Free, open-source desktop app to test your own web forms by US location, emulated device and browser, with recorded scenarios, consent and accessibility checks, and a CI runner.
    • TestMu AI (formerly LambdaTest) - Full-Stack Agentic AI Quality Engineering platform that empowers teams to test intelligently and ship faster.
    • Mocky Balboa - Mock server side network requests in your fullstack apps declaratively at runtime
    • Octomind - AI-powered test case discovery and maintenance.
    • playwright-bdd - BDD-style Playwright testing.
    • QA Wolf - Node.js library for creating browser tests faster.
    • qmax-mcp - MCP server and CLI that gives coding agents independent QA evidence before they declare a web change done: scans a URL for console errors, broken links, accessibility issues, Core Web Vitals, SEO, security headers, and cookies/trackers, then generates and runs a deterministic Playwright repro behind a human-approval gate.
    • Replay QA - Autonomous QA agent for web apps built on Replay's time-travel runtime recording and analysis. It explores an app from its URL, writes and runs Playwright tests, and delivers a root-cause analysis for each failure, backed by evidence from the recorded execution. Free tier, no credit card.
    • tapflow - Self-hosted mobile QA tool that streams iOS simulators and Android emulators to the browser for team-wide testing without local setup.
    • UI Coverage Tool - UI Coverage Tool is an innovative, no-overhead solution for tracking and visualizing UI test coverage — directly on your actual application, not static snapshots.
    • vibe-testing - Open-source MCP server and CLI that scans web app routes and forms, runs browser checks with Playwright, and produces HTML QA reports.
    • VibeView - Run & test iOS, Android, Apple TV and Android TV apps right in your browser, with Roku in beta. Build tests by recording a flow or write steps in plain English, flows can be ran cross-platform, and wired into pull requests. When a step fails - AI agent takes over so the rest of the run still completes, and the report tells you what changed based on failed steps and visual diff.
    • Waterfall AI Test - Open-source visual workbench for Playwright Test Agents that turns requirements into editable plans and verified Playwright tests with human review, repair workflows, version history, and execution evidence.
    • agent-qa - Self-improving QA agent for natural-language web and mobile tests, with execution memory and regression detection.
    • assay - Deterministic command-line QA tool that serves a local web page, drives every control it finds in Chromium through Playwright. No tests to write and no LLM, with a Python API, an HTML report, and a plugin for AI coding agent. MIT, Python.
    • Device Changer - Applies device models, build fingerprints and identifiers to rooted Android test devices to reproduce device-specific bugs.
    • ShipShape - Open-source (MIT) Claude Code plugin that turns a plain-language goal into Playwright browser tests, runs each scenario twice to flag flaky results, and writes an offline HTML report with recorded video.
    • sitelooper - Open-source (MIT) CLI that records a browser flow from plain-English steps with an LLM agent, then compiles it into a standalone Playwright spec that runs in CI with no model, and repairs the spec when the app changes.

    Test Report Diagnostics¶

    • coverage - GitHub Action that compares LCOV and Go coverage reports against the base branch and posts per-file changes as a sticky PR comment.
    • junit-collision-check - Offline Python CLI that detects duplicate test identities and conflicting outcomes across JUnit XML reports before CI report ingestion.
    • Playwright State Lens - Experimental Playwright helper showing selected browser-storage field changes and step screenshots in one local HTML report.
    • pytest-glow-report - Open source (MIT) pytest plugin that writes HTML and JSON reports and keeps run history in SQLite.

    • qarunbook - Free shared test runbook where testers record a pass or fail per platform with screenshots, and an issue marked fixed sends the check back for a retest.
    • skipper - Real-time test execution control via Google Spreadsheet, enabling instant toggle without code changes.
    • TestLink - Open-source test case management system.
    • Testomatio - Modern TCMS allowing sync of manual and automated tests.

    Test Data Management¶

    • TempMailGrab - Disposable email API for temporary inboxes, OTP extraction, verification links, and webhooks in Playwright, Cypress, and CI tests.
    • Temp Mail 24 - Browser-based receive-only temporary inbox for permitted manual signup-flow testing.
    • 8½ Minute Mail - Receive-only temporary inbox for manual email verification testing, with an 8-minute-30-second default lifetime and no account required.
    • TempMail Hub - Free disposable inbox for manual or scripted signup and email-verification testing, with a selectable lifetime from 10 minutes to 7 days and no account required.
    • DATAMIMIC CE - Open-source, deterministic engine for model-driven synthetic test data and PII pseudonymization. Pin a seed and get byte-identical output with a provenance hash on every run. Python, MIT.
    • dbmask - Masks sensitive data in SQL test databases with deterministic fakes and verifies the masking row by row.
    • Dummy Data Lab - Offline, open-source browser tool for transforming CSV or TXT into controlled dummy data and generating linked test datasets without uploading source files.
    • Checklist kiểm thử Web tiếng Việt - Vietnamese-language web form and login testing checklist with copy-paste Vietnamese test data (diacritics, NFC/NFD, +84 phone numbers).
    • JSON Validation Test Cases - Reusable valid, invalid, and edge-case JSON fixtures for testing parsers, validators, APIs, editors, and error handling.
    • Mails.ai - Email inboxes for automated tests: a plus address per test and one call that waits for the email and returns the sign-up code or magic link, with TypeScript and Python SDKs, Cypress and Playwright packages and an MCP server.
    • mailsocket - Inbox API that waits for an email OTP or magic link and returns it as JSON, with Python and TypeScript SDKs and an MCP server.
    • Synth - Open-source test data generator.
    • Personified - Free AI avatar photos of fictional people with typed personas (name, country, age band, mood) for seed data and placeholder users. MIT code, npm package.
    • Touca - Continuous regression testing for behavioral and performance comparisons.
    • test-each - Data-driven testing framework.
    • Sample Files - Free downloadable test file variants across video, audio, document, and archive formats (MP4, MOV, RTF, ZIP, PPTX, etc.), covering codecs, encodings, and edge cases for parser and import testing.
    • ARADURU File Format Test Corpus - Open CC0 corpus of deterministic healthy and intentionally broken XLSX, DOCX, PPTX, ZIP, and PDF fixtures with SHA-256 manifests for file validation, parser, upload, and QA testing.
    • FakeNamely - Free web generator and keyless JSON API for fictional identities, addresses and names across 38 countries. Seeded requests return byte-identical records, so a fixture can be committed; addresses pair a real city and a genuinely valid postal code with an invented street.
    • Código ao Ponto - Free browser-based test data generators and validators for Brazilian documents (CPF, CNPJ, RG, CNH) with valid check digits, plus test credit cards. No signup.
    • postal-code-formats - Postal code formats, validation regexes and 9,000 real sample codes for 31 countries, with every regex tested against the samples in CI.
    • ByteRivet Sample Files - Free browser-based generator for exact-size dummy files from 1 KB to 2 GB in 22 formats (PDF, PNG, JPG, DOCX, XLSX, CSV, JSON, ZIP, MP4, WAV and more) for upload-limit and file-handling tests. Files are built locally, no upload or signup.
    • StanzaAPI Test Data - Free CC0 synthetic test data for regulated B2B formats (IBAN, X12, ISO 20022, GS1, VAT, LEI, UDI, Peppol, Factur-X, CBAM, EPCIS), deterministic and check-digit-valid, as JSON and CSV.
    • FormFiller test data tools - Free browser-based generators for fake addresses, identities, IBANs, test card numbers and bulk CSV/JSON/SQL data in 22
    • Random IMEI Generator - Browser tool that generates 15-digit IMEI numbers with a valid Luhn check digit, exportable as text, JSON or CSV.
    • Brume - Copies a subset of a PostgreSQL database to a test environment, pseudonymizing personal data and keeping foreign keys valid.

    • Bug Magnet - Field-based value suggestions for form testing.

Reports go straight from the browser to Jira, GitHub, Linear, Notion, GitLab, Asana, ClickUp, or Slack, with no third-party server in between. Open source, MIT.
    • Check All - Provides a "Select All" function where missing.

    • Form Filler - Auto-fill large forms with dummy data.
    • Keploy API Test Recorder - Chrome extension that records API calls from your browser session and turns them into API tests.
    • ProxySwitcher - Easy proxy switching for test/prod environments.
    • Requestly - A lightweight proxy to intercept and modify network requests.
    • Spoof Me - Test how a site behaves for users in other browsers, OSes, languages, timezones and screen sizes by switching the whole browser identity. Also available for Firefox.
    • TabQA - Connect, mirror, and control Android devices directly in Chrome via WebUSB without ADB; capture logs, inspect network requests, and record bug reproduction video buffers.

    Accessibility & Usability Testing¶

    • AuditReady - Runs 12 deterministic HTML checks on a page against WCAG 2.2 and returns the matching criterion and a suggested fix for each finding, then turns them into a printable report an agency can hand to its client. Free instant scan; the full report is a one-off $29.
    • Barbwire - Sends AI buyer personas built from your site through the live pages in a real browser, and reports where each one would stop buying, with a step-by-step replay, screenshots and fixes ranked worst first. 10 free runs, no card; paid plans from €49/month.
    • Colour Blindness Simulator - Simulate different types of color blindness.
    • Oh My Android - Free, open-source macOS app for checking Android apps on emulators and phones in dark mode, large font sizes, RTL and TalkBack, with a TalkBack-order accessibility audit.
    • Persqo - Runs AI personas (different ages, devices and patience levels) through a live web app in a real browser and returns ranked issues with screenshots and severity, plus ready-to-paste fix prompts for your coding agent. 3 free test sessions, no card; paid plans from $59/month.
    • RateMyApp Testing Brief Builder - Free, no-account tool for writing mobile usability-testing tasks, expected outcomes, and feedback instructions.
    • RatedWithAI - AI-powered website accessibility scanner that checks for ADA and WCAG 2.2 compliance with instant actionable audits.
    • Site Punchlist - Crawls a whole site with axe-core and groups repeated findings by the shared component causing them, so one fix covers every page it appears on. Publishes which WCAG 2.2 criteria automation can and cannot reach. Free five-page scan, no account.
    • Site Spell Checker - Crawls a live website and flags spelling and grammar mistakes on every page, each shown in context with its page URL. Free one-page scan; the full-site scan is a one-off $99.
    • squirrelscan - Audits websites for accessibility, SEO, performance, and security with 260+ rules and returns exact fixes for your coding agent, from the CLI, cloud, or MCP.
    • VertaaUX CLI - UX, accessibility, and conversion audits from the terminal and CI, with score-based quality gates and PR regression detection.
    • WAVE - Suite of evaluation tools that helps authors make their web content more accessible to individuals with disabilities.

    Test Automation Frameworks¶

    • bareenv - Runs a command once per environment combination (unset, empty, invalid) and reports the ones that break.
    • Bats - Bash Automated Testing System.
    • Jumpstarter - Open source hardware-in-the-loop testing framework for automated testing on real and virtual hardware with CI/CD integration.
    • Cerulion - Open-source robot runtime that records each run and re-executes supported native recordings against new code, exiting 1 with the name of the topic that changed, so a recorded robot run becomes a CI regression test.
    • Robot Framework - Generic open-source automation framework for testing and RPA.
    • ai-natural-language-tests - Generates Cypress and Playwright E2E tests from natural language requirements using LangGraph, ChromaDB, and multi-provider LLM support.
    • OpenTester - MCP-First Testing Framework: AI Agents Can Now Test Like Humans
    • Selenium Boot - Java framework layered on Selenium WebDriver and TestNG. One Maven dependency and one YAML file replace the usual driver-lifecycle, wait, retry and reporting boilerplate, and the raw WebDriver stays accessible.
    • optics-framework - Self-healing test automation for mobile, web and Smart TV. Keyword-driven CSV/YAML tests run on Appium, Selenium and Playwright; when a locator breaks it falls back across XPath, text, OCR and image strategies, with optional AI-powered self-healing.
    • behave - Records how a command-line tool behaves (flags, stdin, exit codes, edge cases) as golden tests and replays them against another implementation, e.g. a Rust or Go rewrite.
    • VeriSpec - Spec-driven quality engineering framework that turns specifications into traceable test strategies, native test suites, and continuous release evidence.
    • blastradius - Test impact analysis for JVM projects (Maven, Gradle, JUnit 5) that runs only the tests affected by a change, using class dependencies recorded by a Java agent.
