    Android¶

    Mobile operating system developed by Google.

    Source

    161 resources imported from JStumpp/awesome-android, dedicated to the public domain (CC0 / Unlicense). Thanks to its maintainers and contributors. Part of the KEEBOX Library · Category: Platforms.

    About this list¶

    Android — mobile operating system developed by Google. This page brings together 161 links about Android, grouped into 5 sections. The largest sections are Libraries, Resources, Development Alternatives, a good place to start if you are exploring the topic for the first time. It belongs to the Platforms category of the KEEBOX Library; see the related lists at the end of the page for neighbouring topics.

    Emulators¶

    • Android Emulator - Official Android emulator integrated into Android Studio.
    • Genymotion - Fast Android emulator for app testing and development. Commercial

    Libraries¶

    Jetpack Compose¶

    • Jetpack Compose - Modern toolkit for building native Android UI with declarative Kotlin APIs and Material 3 support.
    • Haze - Blur and frosted-glass effects for Jetpack Compose and Compose Multiplatform.
    • Showkase - Annotation-processor-based browser for your Jetpack Compose UI elements, colors and typography.

    Architecture¶

    • Circuit - Modern architecture framework for building Android apps with Compose.
    • Decompose - Kotlin Multiplatform library for breaking down your code into lifecycle-aware business logic components.
    • Molecule - Build a StateFlow or Flow stream using Jetpack Compose runtime.
    • Store - Kotlin Multiplatform library for loading, caching and syncing data with a Flow-based API.

    Charts¶

    • MPAndroidChart - An Android chart and graph library supporting scaling and dragging by gesture.
    • Vico - Modern chart library with support for both Jetpack Compose and Android Views.

    Data binding¶

    • Data Binding Library - Official Android Data Binding Library to write declarative layouts and minimize the glue code necessary to bind application logic and layouts.

    Dependency Injection¶

    • Hilt - Official dependency injection library built on top of Dagger for Android.
    • Dagger 2 - A fast dependency injector for Android and Java.
    • Koin - Lightweight dependency injection framework for Kotlin.

    Game Development¶

    • Libgdx - Cross-platform game engine and SDK. Open Source
    • Godot - Cross-platform 2/3D game engine with an IDE and under MIT license.
    • Vuforia - Augmented Reality library. Commercial
    • Unity - Cross-platform game creation system. Commercial

    Security¶

    • Google Tink - Multi-language cross-platform cryptography library providing secure APIs for common cryptographic tasks.

    GUI¶

    • Material Components for Android - Modular and customizable Material Design UI components for Android.
    • Navigation - Framework for building in-app navigation with type-safe argument passing.
    • Pull to refresh - A swipe refresh layout is available in AndroidX.
    • TapTargetView - An implementation of tap targets from the Material Design guidelines for feature discovery.
    • Litho (By Meta) - A declarative framework for building efficient UIs on Android.
    • MaterialDrawer - Simple take on a material design navigation drawer.
    • AppIntro - Library for creating beautiful intro slides for your app.
    • Lottie - Library for rendering After Effects animations natively on Android.
    • Compressor - Lightweight and powerful Android image compression library.
    • Material Dots Indicators - Three Material Dots Indicators styles for View Pagers.
    • Glide - An image loading and caching library for Android focused on smooth scrolling, Recommended by Google.
    • Fresco - An Android library for managing images and the memory they use.
    • Coil - Image loading for Android backed by Kotlin Coroutines.
    • Landscapist - Image loading for Jetpack Compose and Kotlin Multiplatform with Coil, Glide and Fresco as backends.
    • Media3 (ExoPlayer) - Jetpack Media3 support libraries for media use cases, including ExoPlayer, an extensible media player for Android.
    • CameraX - Jetpack library that makes camera app development easier with consistent API across devices.

    JSON¶

    • kotlinx.serialization - Kotlin multiplatform serialization library with JSON support.
    • Gson - Java library used for serializing and deserializing Java objects from and into JSON.
    • Jackson JSON Processor - High-performance JSON processor.
    • Moshi - A modern JSON library for Android and Java.

    Crash monitoring¶

    • Measure - Open source tool to monitor crashes, ANRs, and performance of mobile apps. Can be self-hosted.
    • Sentry Android - Open source error tracking with real-time crash reporting. Commercial (has free tier)
    • Bugsnag - Cross platform error monitoring. Free tier. Support for SDK & NDK. Error reports include data on device, release, user, and allows arbitrary data. Commercial
    • Firebase Crashlytics - Easy crash reporting solution. Commercial (has free tier)

    Networking¶

    • Retrofit - Turns your REST API into a Java interface (continued project).
    • OkHttp - An HTTP+SPDY client for Android and Java applications (continued project).
    • Ktor Client - Asynchronous HTTP client for Kotlin with multiplatform support.
    • Apollo Kotlin - Strongly-typed GraphQL client for Kotlin and Java.
    • Android Volley - Official Android HTTP library that makes networking for easier and faster.
    • Fast-Android-Networking - A Complete Fast Android Networking Library that also support HTTP/2.
    • Wire - Protocol buffers and gRPC for Kotlin, Java and Kotlin Multiplatform.

    Logger¶

    • timber - A logger with a small, extensible API which provides utility on top of Android's normal Log class.
    • Kermit - Kotlin Multiplatform logging library with support for multiple platforms.
    • logger - Simple, pretty and powerful logger for Android.
    • LoggingInterceptor - An OkHttp interceptor which pretty logs request and response data.
    • Logback Android - Logback port to Android which provides a highly configurable logging framework for Android apps.

    Database¶

    • Room - Official SQLite object mapping library with compile-time verification of SQL queries.
    • SQLDelight - Generates typesafe Kotlin APIs from SQL statements with Kotlin Multiplatform support.
    • ObjectBox - Simple but powerful object database, optimized for performance & mobile.
    • requery - Compile time ORM and SQL query library for Java & Android.
    • DBFlow - Fast and powerful ORM with compile-time annotation processing.
    • DbInspector - Provides a simple way to view the contents of the in-app database for debugging purposes.
    • Nitrite Database - A NoSQL embedded document store for Android with MongoDB like API.

    Testing¶

    • Espresso - Official Android UI testing framework for writing reliable UI tests.
    • AndroidX Test - Testing libraries for Android including JUnit rules and Espresso APIs.
    • Roboletric - Unit test framework to run tests inside the JVM on your workstation, not in the emulator.
    • MockK - Mocking library for Kotlin with natural syntax and comprehensive DSL.
    • Turbine - Testing library for Kotlin Flows with simple and expressive assertions.
    • Kotest - Flexible and comprehensive testing framework for Kotlin with multiple testing styles.
    • Maestro - Mobile UI testing framework for end-to-end testing with simple YAML-based syntax.
    • Paparazzi - Render Android screens as images for snapshot testing without a device or emulator.
    • Roborazzi - Screenshot testing library for Android using Robolectric.
    • Ghost in the Droid - Python MCP server for AI agent control of Android and iOS devices via ADB and WebDriverAgent.
    • Droidline - Automate real Android phones from Python, Node.js, C# or a CLI over Wi-Fi, without ADB or root.
    • e2e - End-to-end testing framework for Android and web apps that combines natural-language agent steps with locator-based assertions.

    Tracking¶

    • Countly - Open source mobile & web analytics, push notifications and crash reporting platform, based on Node.js, MongoDB and Linux.
    • Mixpanel - Analytics platform to analyze the users. Commercial

    Maps¶

    • android-maps-utils - Utility library for Google Maps Android API with features like marker clustering and heat maps.
    • Maps Compose - Jetpack Compose components for Google Maps.

    Utility¶

    • Byte Buddy - Runtime code generation library with support for Android.
    • LeakCanary - Catch memory leaks as they occur.

    Debugging Tools¶

    • Linx - Show logcat inside the device for debug builds.
    • Chucker - An HTTP inspector for Android & OkHTTP (like Charles but on device).
    • Android Debug Database - Powerful library for debugging databases and shared preferences in Android applications.
    • Android Debug Bridge - ADB - A command-line tool to assist in debugging Android-powered devices.
    • ADB Enhanced - A command-line wrapper around ADB for developers, so that, developers don't have to remember esoteric version-dependent commands.
    • handsets - Android control CLI that drives devices over ADB with no APK required.
    • Pidcat - A colored command-line ADB wrapper that only shows log entries for a specific application package.
    • scrcpy - Display and control Android devices connected via USB or TCP/IP.

    Wireless¶

    • Kable - Kotlin Asynchronous Bluetooth Low Energy library for Android and other platforms.
    • Nordic Android-BLE-Library - Android BLE library from Nordic Semiconductor for reliable BLE communication.

    Chat & Messaging¶

    • Stream Chat - Comprehensive SDK & Components for real-time chat, powered by Stream. Commercial

    Date & Time¶

    • kotlinx-datetime - A multiplatform Kotlin library for working with date and time.

    Payments¶

    • Square In-App Payments for Android - Integrate Square payments into your mobile app with Digital wallet and stored card support for quick checkout. Commercial

    Google Play¶

    • Google Play Billing - Official library for in-app purchases and subscriptions on Google Play.
    • In-App Updates - Keep your app up to date with flexible and immediate in-app update flows.
    • In-App Review - Prompt users to submit Play Store ratings and reviews without leaving your app.

    Code Quality¶

    • Detekt - Static code analysis tool for Kotlin with over 200 built-in rules.
    • ktlint - Anti-bikeshedding Kotlin linter with built-in formatter.
    • Spotless - Code formatter that supports multiple languages and can enforce consistent formatting in builds.

    Other¶

    • AndroidX - The modern Android development toolkit that replaces the Android Support Library, providing backward-compatible versions of Android framework APIs.
    • Kotlin Coroutines - Library for asynchronous programming with coroutines and Flow for reactive streams.
    • WorkManager - Schedule deferrable and guaranteed background work with a flexible API.
    • Paging - Load and display pages of data from a larger dataset with efficient memory usage.
    • DataStore - Modern data storage solution using Kotlin coroutines and Flow to replace SharedPreferences.
    • Arrow - Functional companion to Kotlin's Standard Library with typed functional programming support.
    • KSP - Kotlin Symbol Processing API for writing lightweight compiler plugins with better performance than kapt.
    • Google Play Services - Library to access Google services, such as account syncing, Google+ (sharing, single sign-on), Google Maps, Location APIs, Google Play Games, Cloud Messaging, Android Device Manager, and others.
    • ML Kit - Mobile SDK for machine learning tasks like barcode scanning, text recognition, and face detection.
    • Google Code Scanner - High-quality barcode scanning without requiring app permissions using Google Play Services.
    • Guava: Google Core Libraries for Java - Collections, caching, primitives support, concurrency libraries, common annotations, string processing, I/O, and so forth.
    • RxJava - Reactive Extensions for the JVM – a library for composing asynchronous and event-based programs using observable sequences for the Java VM.
    • RxAndroid - Adds minimum RxJava bindings for easy writing of reactive Android java code.
    • AboutLibraries - Automatically generates an About this app section, with a list of used libraries.
    • refreshVersions - A Kotlin dsl to simplify dependencies management.
    • Licensee - Gradle plugin which validates the licenses of your dependency graph match what you expect, or it fails your build!

    Code examples¶

    • Now in Android - Official sample app demonstrating modern Android development best practices.
    • Compose Samples - Official sample apps showcasing Jetpack Compose UI toolkit.
    • Android Architecture Blueprints - The Android Architecture Blueprints project demonstrates strategies to help solve or avoid common Android problems.

    Podcasts¶

    • Fragmented - Is the Android developer podcast where Donn Felker and Kaushik Gopal talk about building good software and becoming better Android developers.
    • Android Developers Backstage - Is a podcast by and for Android developers. Hosted by developers from the Android engineering team, this show covers topics of interest to Android programmers, with in-depth discussions and interviews with engineers on the Android team at Google.
    • Android Dialogs - Is a video based podcast, where they have bite-sized conversations with people from the Android community.
    • Talking Kotlin - A Podcast on Kotlin and more.
    • Android Authority - Is a weekly Android podcast hosted by Adam Doud, Joe Hindy, and Jonathan Feist from the Android Authority team.

    Development Alternatives¶

    Cross-Platform¶

    • Flutter - Google's mobile app SDK for high-quality native interfaces for Android and iOS in very quick time.
    • React Native - A framework for building native apps with React.
    • .NET MAUI - .NET Multi-platform App UI, the evolution of Xamarin.Forms, for building native cross-platform apps with .NET and C#.
    • NativeScript - An open-source framework to build native iOS and Android apps with JavaScript from a single code base.
    • Ionic Framework - A framework to build hybrid apps with mobile-optimized HTML, CSS and JS with AngularJS.
    • Apache Cordova - Cordova based applications are, at the core, applications written with web technology: HTML, CSS and JavaScript.
    • Capacitor - Build cross-platform Native Progressive Web Apps for iOS, Android, and the web. Very promising Cordova alternative.
    • Solar2D - Cross-platform framework for creating 2D games and apps (formerly Corona SDK).
    • BeeWare - Write native Android apps in Python using Toga and Briefcase.
    • Flet - Build Flutter apps using Python.
    • Kivy - Open source Python framework for Android apps, packaged with Buildozer.

    Kotlin Multiplatform¶

    • Compose Multiplatform - Jetpack Compose for iOS, Desktop, and Web built on Kotlin Multiplatform.
    • KuiklyUI - Kotlin Multiplatform UI framework supporting Android, iOS, and other platforms.
    • Kotlin coding challenges - Set of programming challenges thats helps to improve whiteboard coding and problem-solving skills.
    • Compose Hot Reload - Hot reload for Compose Multiplatform, by JetBrains.

    Build & Performance¶

    • R8 - Default code shrinker and optimizer for Android apps.
    • ProGuard - Open-source Java bytecode optimizer and shrinker for Android apps.
    • ProGuard Playground - Interactive online tool for visualizing and testing ProGuard and R8 keep rules.
    • Booster - An optimization toolkit for Android applications.
