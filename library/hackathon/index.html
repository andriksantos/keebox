    About this list¶

    Hackathon — running fun and productive hackathons. This page brings together 113 links about Hackathon, grouped into 3 sections. The largest sections are Platforms, Tooling, Guides, a good place to start if you are exploring the topic for the first time. It belongs to the Learn category of the KEEBOX Library; see the related lists at the end of the page for neighbouring topics.

    Platforms¶

    Open Source 🌳¶

    • Civic Tech Exchange - Online platform for Democracy Lab projects. python js
    • DeltaHacks Portal - The attendee & admin portal for DeltaHacks 10, the hackathon for change. ts js
    • Dribdat - Hackathons for impact, based on open data and web standards. python js
    • Hack the Back - An elegant backend, with ready-made GraphQL and REST endpoints. python
    • Hackathon Management System - A comprehensive WordPress plugin by Teplitsa. php
    • Hackerspace3 - Competition Management System for the GovHack Hackathon. ruby
    • Halo - Hackathon Management System built on Django. python
    • Hibiscus - An all-in-one, plug-and-play hackathon platform, created for HackSC. js python
    • JunctionApp - All-in-one hackathon platform for organisers, maintained by Junction. js
    • OpenHackathon - Platform with Git-based Cloud Development Environment based on Next.js. js
    • Opportunity Hack - Skills-Based Volunteering for Social Good, matching people to projects. js python

    Closed Source 🔒¶

    • Agorize (www) - A French company that provides open innovation software.
    • Devfolio (www) - Supporting India's 'largest and fastest growing community of builders'.
    • Devpost (www) - Recognizable U.S. company, whose customers market developer tools and jobs to the community.
    • HackathonHost - White-label platform for hackathons and game jams, covering registration, team formation, weighted judging, certificates and post-event analytics. Flat price per event, free for universities.
    • HackHQ (www) - All-in-one hackathon and competition platform with built-in registration, submissions, judging, and live results. No account required for participants or judges. Launch your event in 30 minutes.
    • HackHub (www, docs) - Canadian company with a featureful event and talent scouting app.
    • Hackworks (docs) - Open innovation challenge platform from experienced event organizers in Canada.
    • Hackyard - Community-driven AI hackathons for solo builders. Small, capped week-long events twice a month: one theme, everyone builds solo with any AI model, and the community votes with counts hidden until close.
    • Stackref (docs) - Internal hackathon and ideation, with cloud provisioning and judging features.
    • TAIKAI (www) - Connects creators and companies, using hackathons, bounties and hiring challenges.

    Organisations¶

    • Hack the Hackathon is an interdisciplinary community exploring scientific collaboration, learning & civic engagement.
    • Hack2Skill hosts events on their own platform and shares resources for technology innovators.
    • Hackathon.com from BeMyApp Corporation promotes events globally, and offers commercial services.
    • HackerEarth is a commercial platform for sourcing, assessing, interviewing, and upskilling developers.
    • HackTribe provides a solution to simplify the hackathon process while maintaining features organisers need.
    • HYPE provides software to help idea and innovation managers collect and manage ideas.
    • Mercer | Mettl sees hackathons as a tool for building tech teams and fostering collaboration.
    • Microsoft sponsors and offers advice for hackathons - see the AcademicContent repo for participants.
    • Nosu (formerly Sprint.dev) proprietary tools to manage hackathons, aiming to upend tech recruiting by quantifying hackathon performance.
    • Random Hacks of Kindness global hackathon series for charities, non-profits and social enterprise (see also: RHOK, Jr.).
    • sprintd - Hackathon advisory and platform with profiles, sprints, teams, outcomes. Built in Switzerland by members of StartHack, available in Early Access.
    • Tulula (discontinued) used to run competitions and hackathons based on an online platform.
    • Unstop provides virtual event platforms to organize hackathons and coding tests.

    • Hack Club - A curated list of hackathons organized for high schoolers.
    • Hackamaps - A global hackathon map and discovery tool for finding events, prize pools, and co-founders.
    • Hack-HQ (www) - A curated, community-driven list of open & upcoming hackathons, updated automatically.

    • Upcoding - Get event details of competitive programming contests, hackathons etc.

    • Team building activities - 64 fun ideas from SessionLab.

    Coaching¶

    • Awesome README - A list to inspire your coaches to motivate your teams to document their efforts ...with panache.
    • HELPq - Queue application with interfaces for mentors and hackers to answer/submit questions, respectively.
    • Hangar - A Slack bot to help with judging and coaching at hackathons.
    • Leadership & Governance - Handbook for open source project, that also applies well for hackathon teams.
    • TreeHacks Slack Mentorship System - A Slack bot that queues requests in a #mentors channel (unmaintained as of 2015).

    Evaluating¶

    • @CivicWhitaker Anthology - Evaluates three years of organizing hackathons in Chicago civic tech.
    • Ansys Developer - A set of judging criteria for hackathons.
    • Evaluation Hackathon - High-level advice on better evaluation from the IPDET hackathons.
    • Eventflare's Journal - Strategies for determining criteria & recruiting judges.
    • Expo Table app - Create a Devpost Expo table frontend.
    • Evaluation Manual - Older guidance sourced from Hacker Earth.
    • Gavel - A project expo judging system by HackMIT that uses fancy math to get good results.
    • MLH Judging Plan - A science-fair type approach to evaluation.
    • Rankeer - An elaborate student project about management and evaluation of hackathons.
    • RunCue - A remote-controlled countdown for pitch and demo day sessions: the organizer runs the clock from a laptop, the room sees a clean auto-advancing timer, and a private cue warns before each team's time runs out.
