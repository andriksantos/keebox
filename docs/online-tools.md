# Free Online Tools

Curated free, open-source developer tools you can use in the browser or self-host: converters, formatters, encoders, image and diagram tools.

!!! tip "17 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Swiss-army knives

- [IT-Tools](https://github.com/CorentinTh/it-tools) - Collection of handy online tools for developers.
- [CyberChef](https://github.com/gchq/CyberChef) - The cyber Swiss army knife: encoding, encryption, compression and data analysis.
- [DevToys](https://github.com/DevToys-app/DevToys) - Swiss army knife for developers (desktop).
- [Stirling-PDF](https://github.com/Stirling-Tools/Stirling-PDF) - Locally hosted web app to do anything with PDFs.

## Images & media

- [Squoosh](https://github.com/GoogleChromeLabs/squoosh) - Make images smaller using best-in-class codecs.
- [SVGOMG / SVGO](https://github.com/svg/svgo) - Tool for optimizing SVG files.
- [Carbon](https://github.com/carbon-app/carbon) - Create and share beautiful images of your source code.
- [ray.so (Raycast)](https://github.com/raycast/ray-so) - Create beautiful images of your code.

## Diagrams & docs

- [Mermaid](https://github.com/mermaid-js/mermaid) - Generate diagrams from Markdown-like text.
- [Excalidraw](https://github.com/excalidraw/excalidraw) - Hand-drawn style whiteboard.
- [draw.io](https://github.com/jgraph/drawio) - Diagramming application.
- [PlantUML](https://github.com/plantuml/plantuml) - Generate diagrams from textual descriptions.
- [readme.so](https://github.com/octokatherine/readme.so) - Easiest way to create a README.

## Code & data

- [JSON Crack](https://github.com/AykutSarac/jsoncrack.com) - Visualize JSON and other data as interactive graphs.
- [regex101 (issues & docs)](https://github.com/firasdib/Regex101) - Online regex tester and debugger.
- [transform.tools](https://github.com/ritz078/transform) - Polyglot web converter (JSON to TS, SVG to JSX and more).
- [Hoppscotch](https://github.com/hoppscotch/hoppscotch) - Online API testing tool.
