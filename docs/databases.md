# Databases

Curated open-source databases, ORMs, migration tools, admin GUIs and learning resources for SQL, NoSQL, time-series and search.

!!! tip "30 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Relational (SQL)

- [PostgreSQL](https://github.com/postgres/postgres) - The world's most advanced open-source relational database.
- [MySQL](https://github.com/mysql/mysql-server) - The popular open-source relational database.
- [MariaDB](https://github.com/MariaDB/server) - Community-developed fork of MySQL.
- [SQLite](https://github.com/sqlite/sqlite) - Small, fast, self-contained SQL database engine.
- [CockroachDB](https://github.com/cockroachdb/cockroach) - Cloud-native, distributed SQL database.
- [TiDB](https://github.com/pingcap/tidb) - Distributed, MySQL-compatible SQL database.

## NoSQL & key-value

- [MongoDB](https://github.com/mongodb/mongo) - Document database built for modern applications.
- [Redis](https://github.com/redis/redis) - In-memory data store used as a database, cache and message broker.
- [Valkey](https://github.com/valkey-io/valkey) - Open-source, high-performance key/value datastore (Redis fork).
- [Apache Cassandra](https://github.com/apache/cassandra) - Highly scalable, partitioned row store.
- [ScyllaDB](https://github.com/scylladb/scylladb) - High-performance NoSQL database compatible with Cassandra.
- [SurrealDB](https://github.com/surrealdb/surrealdb) - Multi-model database for the realtime web.

## Analytics, time-series & search

- [ClickHouse](https://github.com/ClickHouse/ClickHouse) - Real-time analytics columnar database.
- [TimescaleDB](https://github.com/timescale/timescaledb) - Time-series database packaged as a PostgreSQL extension.
- [InfluxDB](https://github.com/influxdata/influxdb) - Scalable datastore for metrics, events and real-time analytics.
- [Elasticsearch](https://github.com/elastic/elasticsearch) - Distributed search and analytics engine.
- [Meilisearch](https://github.com/meilisearch/meilisearch) - Lightning-fast, typo-tolerant search engine.
- [Typesense](https://github.com/typesense/typesense) - Open-source alternative to Algolia.

## Backend platforms

- [Supabase](https://github.com/supabase/supabase) - Postgres development platform: database, auth, storage and realtime.
- [Appwrite](https://github.com/appwrite/appwrite) - Open-source backend for web, mobile and AI apps.
- [PocketBase](https://github.com/pocketbase/pocketbase) - Open-source backend in a single file.
- [Hasura](https://github.com/hasura/graphql-engine) - Instant GraphQL and REST APIs on your data.

## Tools & GUIs

- [DBeaver](https://github.com/dbeaver/dbeaver) - Free universal database tool and SQL client.
- [Beekeeper Studio](https://github.com/beekeeper-studio/beekeeper-studio) - Modern, easy-to-use SQL editor and database manager.
- [pgcli](https://github.com/dbcli/pgcli) - Postgres CLI with auto-completion and syntax highlighting.
- [Flyway](https://github.com/flyway/flyway) - Database migrations made easy.
- [Atlas](https://github.com/ariga/atlas) - Manage your database schema as code.
