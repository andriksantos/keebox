# Java & Kotlin

Curated Java and Kotlin backend frameworks, libraries, build tools and learning resources for building enterprise-grade services.

!!! tip "22 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Frameworks

- [Spring Boot](https://github.com/spring-projects/spring-boot) - Create stand-alone, production-grade Spring applications.
- [Quarkus](https://github.com/quarkusio/quarkus) - Supersonic Subatomic Java, built for Kubernetes and the cloud.
- [Micronaut](https://github.com/micronaut-projects/micronaut-core) - Modern, JVM-based framework for microservices.
- [Ktor](https://github.com/ktorio/ktor) - Framework for asynchronous servers and clients in Kotlin.
- [Javalin](https://github.com/javalin/javalin) - Simple and lightweight web framework for Java and Kotlin.
- [Vert.x](https://github.com/eclipse-vertx/vert.x) - Reactive toolkit for the JVM.

## Libraries

- [Hibernate ORM](https://github.com/hibernate/hibernate-orm) - Idiomatic persistence for Java and relational databases.
- [Lombok](https://github.com/projectlombok/lombok) - Reduce boilerplate code in Java.
- [Jackson](https://github.com/FasterXML/jackson-databind) - General data-binding package for Java (JSON).
- [Guava](https://github.com/google/guava) - Google core libraries for Java.
- [MapStruct](https://github.com/mapstruct/mapstruct) - Code generator for type-safe bean mappings.
- [Resilience4j](https://github.com/resilience4j/resilience4j) - Fault tolerance library designed for functional programming.
- [kotlinx.coroutines](https://github.com/Kotlin/kotlinx.coroutines) - Library support for Kotlin coroutines.

## Build & testing

- [Gradle](https://github.com/gradle/gradle) - Adaptable, fast automation for all kinds of builds.
- [Maven](https://github.com/apache/maven) - Software project management and comprehension tool.
- [JUnit](https://github.com/junit-team/junit-framework) - The programmer-friendly testing framework for Java.
- [Mockito](https://github.com/mockito/mockito) - Most popular mocking framework for Java.
- [Testcontainers Java](https://github.com/testcontainers/testcontainers-java) - Throwaway Docker containers for integration tests.

## Learn

- [Awesome Java](https://github.com/akullpp/awesome-java) - Curated list of awesome frameworks, libraries and software for Java.
- [Awesome Kotlin](https://github.com/Heapy/awesome-kotlin) - Curated list of awesome Kotlin related stuff.
- [Java Design Patterns](https://github.com/iluwatar/java-design-patterns) - Design patterns implemented in Java.
- [JavaGuide](https://github.com/Snailclimb/JavaGuide) - Java learning and interview guide.
