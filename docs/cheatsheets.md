# Cheat Sheets

Curated developer cheat sheets and quick references for Git, Docker, regex, SQL, shell, Python, JavaScript and more.

!!! tip "17 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Collections

- [cheat.sh](https://github.com/chubin/cheat.sh) - The only cheat sheet you need, from the terminal.
- [Rico's cheatsheets (devhints)](https://github.com/rstacruz/cheatsheets) - TL;DR cheat sheets for dozens of tools and languages.
- [Awesome Cheatsheets](https://github.com/LeCoupa/awesome-cheatsheets) - Cheat sheets for popular languages, frameworks and tools.
- [QuickRef.ME](https://github.com/Fechin/reference) - Collection of cheat sheets for developers.
- [tldr pages](https://github.com/tldr-pages/tldr) - Simplified, example-based man pages.
- [cheat](https://github.com/cheat/cheat) - Create and view interactive cheat sheets on the command line.

## Git & GitHub

- [Git Cheat Sheet](https://github.com/arslanbilal/git-cheat-sheet) - Git and Git Flow cheat sheet.
- [Git Tips](https://github.com/git-tips/tips) - Most commonly used git tips and tricks.
- [Oh Shit, Git!?! (source)](https://github.com/ksylor/ohshitgit) - How to get out of common git messes.

## Languages & tools

- [Python Cheatsheet](https://github.com/gto76/python-cheatsheet) - Comprehensive Python cheat sheet.
- [JavaScript Questions](https://github.com/lydiahallie/javascript-questions) - Advanced JavaScript questions with explanations.
- [React TypeScript Cheatsheets](https://github.com/typescript-cheatsheets/react) - Cheat sheets for experienced React developers getting started with TypeScript.
- [Docker Cheat Sheet](https://github.com/wsargent/docker-cheat-sheet) - Docker cheat sheet.
- [Kubernetes cheat sheet (kubectl)](https://github.com/dennyzhang/cheatsheet-kubernetes-A4) - Kubernetes cheat sheet in A4 format.
- [Learn Regex](https://github.com/ziishaned/learn-regex) - Learn regex the easy way.
- [Pure Bash Bible](https://github.com/dylanaraps/pure-bash-bible) - Collection of pure bash alternatives to external processes.
- [Vim Cheat Sheet](https://github.com/rtorr/vim-cheat-sheet) - Vim cheat sheet in many languages.
