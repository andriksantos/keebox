## Official Packages

- [Golang Server](https://ganigeorgiev.com/pocketbase/pocketbase/releases) - The main PocketBase server.

## Forks

- [PostgreBase](https://github.com/zhenruyan/postgrebase) - A PocketBase fork with PostgreSQL and MySQL support alongside SQLite, a built-in MCP server and Redis or in-memory caching, keeping the PocketBase API.
- [PocketOne](https://pocketone.dev) - An open, community-driven fork of PocketBase. Features live in Go extensions that connect only through versioned contracts, so anyone can contribute (PITR, bulk mail, WASM, an updated JSVM, and more) without touching core. Not affiliated with PocketBase.
