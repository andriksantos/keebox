# Data Engineering & Analytics

Curated data engineering, analytics and business intelligence tools: pipelines, orchestration, transformation, warehouses and dashboards.

!!! tip "21 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Orchestration & pipelines

- [Apache Airflow](https://github.com/apache/airflow) - Platform to author, schedule and monitor workflows.
- [Dagster](https://github.com/dagster-io/dagster) - Orchestration platform for data assets.
- [Prefect](https://github.com/PrefectHQ/prefect) - Workflow orchestration framework for resilient data pipelines.
- [Airbyte](https://github.com/airbytehq/airbyte) - Data integration platform with hundreds of connectors.
- [dlt](https://github.com/dlt-hub/dlt) - Python library to load data into well-structured datasets.
- [Kestra](https://github.com/kestra-io/kestra) - Event-driven declarative orchestration platform.

## Processing & transformation

- [dbt Core](https://github.com/dbt-labs/dbt) - Transform data in your warehouse using SQL.
- [Apache Spark](https://github.com/apache/spark) - Unified engine for large-scale data analytics.
- [Apache Kafka](https://github.com/apache/kafka) - Distributed event streaming platform.
- [Apache Flink](https://github.com/apache/flink) - Stream processing framework.
- [Great Expectations](https://github.com/fivetran/great_expectations) - Data quality and validation framework.

## BI & dashboards

- [Apache Superset](https://github.com/apache/superset) - Modern data exploration and visualization platform.
- [Metabase](https://github.com/metabase/metabase) - The simplest way to get analytics and BI for your company.
- [Grafana](https://github.com/grafana/grafana) - Dashboards for metrics, logs and business data.
- [Evidence](https://github.com/evidence-dev/evidence) - Business intelligence as code with SQL and Markdown.
- [Lightdash](https://github.com/lightdash/lightdash) - Open-source BI tool built on dbt.

## Learn data

- [Data Engineering Zoomcamp](https://github.com/DataTalksClub/data-engineering-zoomcamp) - Free 9-week data engineering course.
- [Awesome Data Engineering](https://github.com/igorbarinov/awesome-data-engineering) - Curated list of data engineering tools.
- [Data Engineer Handbook](https://github.com/DataExpert-io/data-engineer-handbook) - Links to everything you need to learn data engineering.
- [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets) - High-quality open datasets by topic.
- [Awesome BI](https://github.com/thenaturalist/awesome-business-intelligence) - Actually awesome business intelligence tools.
