# Go

Curated Go (Golang) frameworks, libraries, tools and learning resources for building fast, reliable backend services and CLIs.

!!! tip "21 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Web frameworks

- [Gin](https://github.com/gin-gonic/gin) - High-performance HTTP web framework.
- [Echo](https://github.com/labstack/echo) - High performance, minimalist web framework.
- [Fiber](https://github.com/gofiber/fiber) - Express-inspired web framework built on Fasthttp.
- [chi](https://github.com/go-chi/chi) - Lightweight, idiomatic router for HTTP services.
- [Huma](https://github.com/danielgtaylor/huma) - Modern framework for REST APIs with OpenAPI 3.1.

## Libraries

- [GORM](https://github.com/go-gorm/gorm) - The fantastic ORM library for Go.
- [sqlc](https://github.com/sqlc-dev/sqlc) - Generate type-safe code from SQL.
- [pgx](https://github.com/jackc/pgx) - PostgreSQL driver and toolkit for Go.
- [Cobra](https://github.com/spf13/cobra) - Library for creating powerful modern CLI applications.
- [Viper](https://github.com/spf13/viper) - Complete configuration solution for Go applications.
- [zap](https://github.com/uber-go/zap) - Blazing fast, structured, leveled logging.
- [testify](https://github.com/stretchr/testify) - Toolkit with common assertions and mocks.
- [Bubble Tea](https://github.com/charmbracelet/bubbletea) - Powerful little TUI framework.

## Tooling

- [golangci-lint](https://github.com/golangci/golangci-lint) - Fast linters runner for Go.
- [Air](https://github.com/air-verse/air) - Live reload for Go apps.
- [GoReleaser](https://github.com/goreleaser/goreleaser) - Release engineering, simplified.
- [Delve](https://github.com/go-delve/delve) - Debugger for the Go programming language.

## Learn Go

- [Awesome Go](https://github.com/avelino/awesome-go) - Curated list of awesome Go frameworks, libraries and software.
- [Learn Go with Tests](https://github.com/quii/learn-go-with-tests) - Learn Go with test-driven development.
- [Go by Example](https://github.com/mmcgrana/gobyexample) - Hands-on introduction to Go using annotated example programs.
- [Go Project Layout](https://github.com/golang-standards/project-layout) - Standard Go project layout.
