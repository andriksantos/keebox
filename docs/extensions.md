# Editor & Browser Extensions

Curated VS Code extensions, editor tools and browser extensions that make developers more productive.

!!! tip "21 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## VS Code extensions

- [GitLens](https://github.com/gitkraken/vscode-gitlens) - Supercharge Git inside VS Code.
- [Error Lens](https://github.com/usernamehw/vscode-error-lens) - Improve highlighting of errors, warnings and diagnostics.
- [Prettier for VS Code](https://github.com/prettier/prettier-vscode) - Code formatter using Prettier.
- [ESLint for VS Code](https://github.com/microsoft/vscode-eslint) - ESLint integration for VS Code.
- [Tailwind CSS IntelliSense](https://github.com/tailwindlabs/tailwindcss-intellisense) - Intelligent Tailwind CSS tooling.
- [Live Server](https://github.com/ritwickdey/vscode-live-server) - Launch a local development server with live reload.
- [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) - Material Design icons for VS Code.
- [Code Spell Checker](https://github.com/streetsidesoftware/vscode-spell-checker) - Spell checker for source code.
- [Todo Tree](https://github.com/Gruntfuggly/todo-tree) - Show TODO and FIXME tags in a tree view.

## Editors

- [VS Code](https://github.com/microsoft/vscode) - Visual Studio Code — open-source code editor.
- [VSCodium](https://github.com/VSCodium/vscodium) - Freely-licensed VS Code binaries without telemetry.
- [Zed](https://github.com/zed-industries/zed) - High-performance, multiplayer code editor.
- [LazyVim](https://github.com/LazyVim/LazyVim) - Neovim setup powered by lazy.nvim.

## Browser extensions

- [React Developer Tools](https://github.com/react/react) - React DevTools are part of the React repository.
- [Vue.js devtools](https://github.com/vuejs/devtools) - Browser devtools extension for debugging Vue apps.
- [uBlock Origin](https://github.com/gorhill/uBlock) - Efficient wide-spectrum content blocker.
- [Refined GitHub](https://github.com/refined-github/refined-github) - Browser extension that simplifies the GitHub interface.
- [Octotree](https://github.com/ovity/octotree) - Code tree for GitHub repositories.
- [JSON Viewer](https://github.com/tulios/json-viewer) - Highlighter and viewer for JSON in the browser.
