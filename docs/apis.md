# APIs

Curated tools and resources to design, build, document, test and consume REST, GraphQL and gRPC APIs.

!!! tip "21 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## API clients

- [Bruno](https://github.com/usebruno/bruno) - Open-source, Git-friendly IDE for exploring and testing APIs.
- [Hoppscotch](https://github.com/hoppscotch/hoppscotch) - Open-source API development ecosystem.
- [Insomnia](https://github.com/Kong/insomnia) - Open-source API client for GraphQL, REST, WebSockets and gRPC.
- [HTTPie](https://github.com/httpie/cli) - Human-friendly command-line HTTP client.

## Design & documentation

- [OpenAPI Specification](https://github.com/OAI/OpenAPI-Specification) - The standard for describing HTTP APIs.
- [Swagger UI](https://github.com/swagger-api/swagger-ui) - Interactive documentation for OpenAPI definitions.
- [Redoc](https://github.com/Redocly/redoc) - Beautiful API documentation from OpenAPI.
- [Scalar](https://github.com/scalar/scalar) - Modern API reference and client for OpenAPI.
- [Spectral](https://github.com/stoplightio/spectral) - Flexible JSON/YAML linter for OpenAPI and AsyncAPI.

## GraphQL & gRPC

- [GraphQL spec](https://github.com/graphql/graphql-spec) - The GraphQL specification.
- [Apollo Server](https://github.com/apollographql/apollo-server) - Spec-compliant, production-ready GraphQL server.
- [GraphQL Yoga](https://github.com/graphql-hive/graphql-yoga) - Fully-featured GraphQL server.
- [gRPC](https://github.com/grpc/grpc) - High-performance, open-source universal RPC framework.
- [Connect RPC](https://github.com/connectrpc/connect-go) - Simple, reliable, interoperable gRPC-compatible APIs.

## Gateways & mocks

- [Kong](https://github.com/Kong/kong) - Cloud-native API gateway.
- [Prism](https://github.com/stoplightio/prism) - Turn any OpenAPI file into a mock server.
- [json-server](https://github.com/typicode/json-server) - Full fake REST API with zero coding.

## Learn & discover

- [Public APIs](https://github.com/public-apis/public-apis) - Collective list of free APIs.
- [API Security Checklist](https://github.com/shieldfy/API-Security-Checklist) - Checklist of the most important security countermeasures for APIs.
- [Microsoft REST API Guidelines](https://github.com/microsoft/api-guidelines) - Guidelines for designing REST APIs.
- [Awesome API DevTools](https://github.com/yosriady/awesome-api-devtools) - Curated list of API tools.
