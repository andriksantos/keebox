# Templates & Starters

Curated boilerplates, starter kits, admin dashboards and landing page templates to start new projects faster.

!!! tip "18 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Full-stack starters

- [create-t3-app](https://github.com/t3-oss/create-t3-app) - The best way to start a full-stack, typesafe Next.js app.
- [Next.js examples](https://github.com/vercel/next.js) - Hundreds of official examples in the Next.js repo.
- [Open SaaS](https://github.com/wasp-lang/open-saas) - Free, open-source SaaS starter for React and Node.js.
- [Turborepo](https://github.com/vercel/turborepo) - High-performance build system and monorepo starters.
- [Full Stack FastAPI Template](https://github.com/fastapi/full-stack-fastapi-template) - FastAPI, React, SQLModel, PostgreSQL, Docker and more.
- [Cookiecutter Django](https://github.com/cookiecutter/cookiecutter-django) - Framework for jumpstarting production-ready Django projects.

## Admin dashboards

- [TailAdmin](https://github.com/TailAdmin/free-react-tailwind-admin-dashboard) - Free React Tailwind admin dashboard template.
- [shadcn-admin](https://github.com/satnaing/shadcn-admin) - Admin dashboard UI built with shadcn and Vite.
- [Refine](https://github.com/refinedev/refine) - React framework for building internal tools and admin panels.
- [React Admin](https://github.com/marmelab/react-admin) - Framework for B2B apps on top of REST/GraphQL APIs.
- [CoreUI](https://github.com/coreui/coreui-free-react-admin-template) - Free React admin dashboard template.

## Landing pages & sites

- [Astro themes (AstroWind)](https://github.com/arthelokyo/astrowind) - Free Astro and Tailwind CSS template for websites and landing pages.
- [HTML5 Boilerplate](https://github.com/h5bp/html5-boilerplate) - Professional front-end template.
- [Start Bootstrap](https://github.com/StartBootstrap/startbootstrap-agency) - Free one-page Bootstrap theme.
- [Magic UI](https://github.com/magicuidesign/magicui) - Animated UI components and templates.
