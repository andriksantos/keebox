# Python

Curated Python libraries, frameworks, tooling and learning resources for web development, data science, automation and AI.

!!! tip "33 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Tooling

- [uv](https://github.com/astral-sh/uv) - Extremely fast Python package and project manager, written in Rust.
- [Ruff](https://github.com/astral-sh/ruff) - Extremely fast Python linter and code formatter.
- [Poetry](https://github.com/python-poetry/poetry) - Dependency management and packaging made easy.
- [mypy](https://github.com/python/mypy) - Optional static typing for Python.
- [pytest](https://github.com/pytest-dev/pytest) - Simple, powerful testing framework.
- [pre-commit](https://github.com/pre-commit/pre-commit) - Framework for managing multi-language git hooks.

## Web frameworks

- [FastAPI](https://github.com/fastapi/fastapi) - High-performance framework for building APIs with type hints.
- [Django](https://github.com/django/django) - The web framework for perfectionists with deadlines.
- [Flask](https://github.com/pallets/flask) - Lightweight WSGI web application framework.
- [Litestar](https://github.com/litestar-org/litestar) - Production-ready, async ASGI API framework.
- [Reflex](https://github.com/reflex-dev/reflex) - Build full-stack web apps in pure Python.

## Data & science

- [pandas](https://github.com/pandas-dev/pandas) - Flexible data analysis and manipulation library.
- [Polars](https://github.com/pola-rs/polars) - Lightning-fast DataFrame library powered by Rust.
- [NumPy](https://github.com/numpy/numpy) - The fundamental package for scientific computing.
- [DuckDB](https://github.com/duckdb/duckdb) - In-process analytical SQL database.
- [Jupyter Notebook](https://github.com/jupyter/notebook) - The interactive notebook for code, text and charts.
- [marimo](https://github.com/marimo-team/marimo) - Reactive Python notebooks stored as pure Python.
- [Matplotlib](https://github.com/matplotlib/matplotlib) - Comprehensive plotting library.
- [Plotly](https://github.com/plotly/plotly.py) - Interactive, browser-based graphing library.

## Libraries

- [Requests](https://github.com/psf/requests) - HTTP for Humans.
- [HTTPX](https://github.com/encode/httpx) - Next-generation HTTP client with sync and async APIs.
- [Pydantic](https://github.com/pydantic/pydantic) - Data validation using Python type hints.
- [SQLAlchemy](https://github.com/sqlalchemy/sqlalchemy) - The Python SQL toolkit and ORM.
- [Celery](https://github.com/celery/celery) - Distributed task queue.
- [Rich](https://github.com/Textualize/rich) - Rich text and beautiful formatting in the terminal.
- [Textual](https://github.com/Textualize/textual) - Build sophisticated terminal user interfaces.
- [Typer](https://github.com/fastapi/typer) - Build great CLIs based on type hints.
- [Scrapy](https://github.com/scrapy/scrapy) - Fast, high-level web crawling and scraping framework.
- [Playwright for Python](https://github.com/microsoft/playwright-python) - Browser automation for Chromium, Firefox and WebKit.

## Learn Python

- [Awesome Python](https://github.com/vinta/awesome-python) - The classic curated list of Python frameworks and libraries.
- [30 Days Of Python](https://github.com/Asabeneh/30-Days-Of-Python) - Step-by-step 30-day challenge to learn Python.
- [The Algorithms - Python](https://github.com/TheAlgorithms/Python) - All algorithms implemented in Python.
- [Python Patterns](https://github.com/faif/python-patterns) - Collection of design patterns and idioms in Python.
