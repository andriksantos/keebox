# Learning & Free Resources

Free books, courses, roadmaps, public APIs and developer tools with free tiers to grow your software development career.

!!! tip "18 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Roadmaps & career

- [Developer Roadmap](https://github.com/nilbuild/developer-roadmap) - Interactive roadmaps and guides to grow as a developer.
- [Coding Interview University](https://github.com/jwasham/coding-interview-university) - Complete computer science study plan to become a software engineer.
- [Tech Interview Handbook](https://github.com/yangshun/tech-interview-handbook) - Curated materials to ace your coding interviews.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) - Learn how to design large-scale systems.
- [Every Programmer Should Know](https://github.com/mtdvio/every-programmer-should-know) - Technical things every software developer should know.

## Free courses & books

- [freeCodeCamp](https://github.com/freeCodeCamp/freeCodeCamp) - Free curriculum to learn math, programming and computer science.
- [Free Programming Books](https://github.com/EbookFoundation/free-programming-books) - Freely available programming books in many languages.
- [OSSU Computer Science](https://github.com/ossu/computer-science) - Path to a free self-taught education in computer science.
- [The Odin Project](https://github.com/TheOdinProject/curriculum) - Free full-stack curriculum.
- [Papers We Love](https://github.com/papers-we-love/papers-we-love) - Academic computer science papers and communities.

## Learn by building

- [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) - Master programming by recreating your favorite technologies from scratch.
- [Project Based Learning](https://github.com/practical-tutorials/project-based-learning) - Curated list of project-based tutorials.
- [App Ideas](https://github.com/florinpop17/app-ideas) - Collection of application ideas to improve your coding skills.
- [First Contributions](https://github.com/firstcontributions/first-contributions) - Help beginners make their first open-source contribution.

## Free APIs & services

- [Public APIs](https://github.com/public-apis/public-apis) - Collective list of free APIs for software development.
- [Datacircle API](https://api.datacircle.dev/v1) - Find the best GTM APIs, free and open with no key. More at [datacircle.dev](https://datacircle.dev).
- [Free for Dev](https://github.com/ripienaar/free-for-dev) - SaaS, PaaS and IaaS offerings with free tiers for developers.
- [gitignore templates](https://github.com/github/gitignore) - Collection of useful .gitignore templates.
- [Awesome](https://github.com/sindresorhus/awesome) - The original list of awesome lists.
