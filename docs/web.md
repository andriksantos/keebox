# Web Development

Curated front-end and full-stack web development frameworks, build tools, UI libraries, testing tools and learning resources.

!!! tip "39 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Frameworks

- [React](https://github.com/react/react) - Library for web and native user interfaces.
- [Vue](https://github.com/vuejs/core) - Progressive, incrementally-adoptable JavaScript framework.
- [Svelte](https://github.com/sveltejs/svelte) - Cybernetically enhanced web apps.
- [Angular](https://github.com/angular/angular) - Platform for building mobile and desktop web applications.
- [Next.js](https://github.com/vercel/next.js) - The React framework for the web.
- [Nuxt](https://github.com/nuxt/nuxt) - The intuitive Vue framework.
- [Astro](https://github.com/withastro/astro) - Web framework for content-driven websites.
- [React Router](https://github.com/remix-run/react-router) - Declarative routing and full-stack framework for React.
- [htmx](https://github.com/bigskysoftware/htmx) - High power tools for HTML.

## Tooling & runtimes

- [Vite](https://github.com/vitejs/vite) - Next-generation front-end tooling.
- [TypeScript](https://github.com/microsoft/TypeScript) - JavaScript with syntax for types.
- [Bun](https://github.com/oven-sh/bun) - All-in-one JavaScript runtime, bundler, test runner and package manager.
- [Deno](https://github.com/denoland/deno) - Modern runtime for JavaScript and TypeScript.
- [pnpm](https://github.com/pnpm/pnpm) - Fast, disk space efficient package manager.
- [Biome](https://github.com/biomejs/biome) - Fast formatter and linter for web projects.
- [Prettier](https://github.com/prettier/prettier) - Opinionated code formatter.
- [ESLint](https://github.com/eslint/eslint) - Find and fix problems in your JavaScript code.

## Styling & UI

- [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) - Utility-first CSS framework.
- [shadcn/ui](https://github.com/shadcn-ui/ui) - Beautifully designed, accessible components you copy into your app.
- [Bootstrap](https://github.com/twbs/bootstrap) - The most popular HTML, CSS and JS framework.
- [Radix UI Primitives](https://github.com/radix-ui/primitives) - Unstyled, accessible components for React.
- [daisyUI](https://github.com/saadeghi/daisyui) - Component library for Tailwind CSS.
- [Animate.css](https://github.com/animate-css/animate.css) - Cross-browser library of CSS animations.

## Data, state & validation

- [TanStack Query](https://github.com/TanStack/query) - Powerful asynchronous state management and data fetching.
- [Zustand](https://github.com/pmndrs/zustand) - Small, fast and scalable state management.
- [Zod](https://github.com/colinhacks/zod) - TypeScript-first schema validation with static type inference.
- [tRPC](https://github.com/trpc/trpc) - End-to-end typesafe APIs made easy.
- [Prisma](https://github.com/prisma/orm) - Next-generation ORM for Node.js and TypeScript.
- [Drizzle ORM](https://github.com/drizzle-team/drizzle-orm) - Headless TypeScript ORM.

## Testing

- [Playwright](https://github.com/microsoft/playwright) - Reliable end-to-end testing for modern web apps.
- [Vitest](https://github.com/vitest-dev/vitest) - Next-generation testing framework powered by Vite.
- [Cypress](https://github.com/cypress-io/cypress) - Fast, easy and reliable testing for anything that runs in a browser.
- [React Testing Library](https://github.com/testing-library/react-testing-library) - Simple and complete React DOM testing utilities.
