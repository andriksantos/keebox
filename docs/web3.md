# Blockchain & Web3

Curated blockchain and Web3 developer tools: smart contract frameworks, client libraries, security tools and learning resources.

!!! tip "16 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Smart contract frameworks

- [Foundry](https://github.com/foundry-rs/foundry) - Blazing fast, portable and modular toolkit for Ethereum development.
- [Hardhat](https://github.com/NomicFoundation/hardhat) - Ethereum development environment for professionals.
- [OpenZeppelin Contracts](https://github.com/OpenZeppelin/openzeppelin-contracts) - Library for secure smart contract development.
- [Solidity](https://github.com/argotorg/solidity) - The Solidity contract-oriented programming language.
- [Anchor (Solana)](https://github.com/otter-sec/anchor) - Framework for Solana programs.

## Client libraries

- [viem](https://github.com/wevm/viem) - TypeScript interface for Ethereum.
- [ethers.js](https://github.com/ethers-io/ethers.js) - Complete Ethereum library and wallet implementation.
- [web3.py](https://github.com/ApeWorX/web3.py) - Python interface for interacting with Ethereum.
- [wagmi](https://github.com/wevm/wagmi) - Reactive primitives for Ethereum apps.

## Security

- [Slither](https://github.com/crytic/slither) - Static analyzer for Solidity.
- [Echidna](https://github.com/crytic/echidna) - Ethereum smart contract fuzzer.
- [Smart Contract Security Verification Standard](https://github.com/ComposableSecurity/SCSVS) - Checklist for securing smart contracts.

## Learn

- [Awesome Ethereum](https://github.com/ttumiel/Awesome-Ethereum) - Curated list of Ethereum resources.
- [Awesome Solidity](https://github.com/bkrem/awesome-solidity) - Curated list of Solidity resources and libraries.
- [Solidity by Example](https://github.com/Cyfrin/solidity-by-example.github.io) - Introduction to Solidity with simple examples.
- [Ethernaut](https://github.com/OpenZeppelin/ethernaut) - Web3/Solidity based wargame for learning security.
