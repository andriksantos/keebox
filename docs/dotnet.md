# C# & .NET

Curated C# and .NET frameworks, libraries, tools and learning resources for web, desktop, cloud and game development.

!!! tip "20 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Frameworks

- [ASP.NET Core](https://github.com/dotnet/aspnetcore) - Cross-platform framework for building web apps and APIs.
- [.NET runtime](https://github.com/dotnet/runtime) - The .NET runtime and base class libraries.
- [.NET MAUI](https://github.com/dotnet/maui) - Cross-platform native UI for mobile and desktop.
- [Avalonia](https://github.com/AvaloniaUI/Avalonia) - Cross-platform UI framework for .NET.
- [Orleans](https://github.com/dotnet/orleans) - Cloud-native distributed application framework.

## Libraries

- [Entity Framework Core](https://github.com/dotnet/efcore) - Modern object-database mapper for .NET.
- [Dapper](https://github.com/DapperLib/Dapper) - Simple object mapper for .NET.
- [Serilog](https://github.com/serilog/serilog) - Simple .NET logging with fully-structured events.
- [Polly](https://github.com/App-vNext/Polly) - Resilience and transient-fault-handling library.
- [FluentValidation](https://github.com/FluentValidation/FluentValidation) - Popular .NET validation library.
- [MediatR](https://github.com/LuckyPennySoftware/MediatR) - Simple mediator implementation in .NET.
- [Hangfire](https://github.com/HangfireIO/Hangfire) - Background job processing for .NET.

## Testing & tools

- [xUnit](https://github.com/xunit/xunit) - Community-focused unit testing tool for .NET.
- [NSubstitute](https://github.com/nsubstitute/NSubstitute) - Friendly substitute for .NET mocking libraries.
- [BenchmarkDotNet](https://github.com/dotnet/BenchmarkDotNet) - Powerful .NET library for benchmarking.
- [ILSpy](https://github.com/icsharpcode/ILSpy) - .NET decompiler and assembly browser.

## Learn

- [Awesome .NET](https://github.com/quozd/awesome-dotnet) - Collection of awesome .NET libraries, tools and frameworks.
- [Awesome .NET Core](https://github.com/thangchung/awesome-dotnet-core) - Curated list of awesome .NET Core libraries and tools.
- [eShop reference app](https://github.com/dotnet/eShop) - Reference .NET application implementing an e-commerce site.
- [Clean Architecture template](https://github.com/jasontaylordev/CleanArchitecture) - Clean Architecture solution template for ASP.NET Core.
