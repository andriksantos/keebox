# Transparency

KEEBOX LIST™ is a one-person project with community contributions. Here is exactly how it runs and what your contributions pay for.

## How the site runs

| Item | How it works |
| --- | --- |
| **Hosting** | GitHub Pages (free for open-source projects). |
| **Domain** | Served from [andriksantos.com/keebox](https://andriksantos.com/keebox/). |
| **Link checking** | An automated job checks every link monthly and opens a report. |
| **Content** | 35 hand-written topic guides + the [Library](library/index.md) of 444 public-domain lists. |
| **Ads** | None. KEEBOX does not show ads or sell your data. |

## What donations pay for

1. **Time** — curating new resources, reviewing contributions and fixing broken links every month.
2. **New sections** — more topic guides and more content in Spanish.
3. **Library updates** — re-importing the 444 lists so they stay current.
4. **Domain and tools** used to build and maintain the site.

## Monthly goal

The progress bar at the top of this page shows the current month. When the goal is reached, the extra goes to the next new section, and we announce it in the banner.

## Updates

This page is updated whenever the goal or the use of funds changes. Questions? Write to [andricksantos1@gmail.com](mailto:andricksantos1@gmail.com).
