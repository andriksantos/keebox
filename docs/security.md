# Security

Curated cybersecurity tools and learning resources for developers: secrets scanning, dependency auditing, web security, penetration testing and secure coding.

!!! tip "26 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Code & dependency scanning

- [Semgrep](https://github.com/semgrep/semgrep) - Lightweight static analysis for many languages.
- [Trivy](https://github.com/aquasecurity/trivy) - Find vulnerabilities, misconfigurations and secrets in containers, code and clouds.
- [Grype](https://github.com/anchore/grype) - Vulnerability scanner for container images and filesystems.
- [OSV-Scanner](https://github.com/google/osv-scanner) - Vulnerability scanner using the OSV database.
- [CodeQL](https://github.com/github/codeql) - Semantic code analysis engine by GitHub.
- [Bandit](https://github.com/PyCQA/bandit) - Find common security issues in Python code.

## Secrets

- [Gitleaks](https://github.com/gitleaks/gitleaks) - Find secrets in git repositories.
- [TruffleHog](https://github.com/trufflesecurity/trufflehog) - Find, verify and analyze leaked credentials.
- [SOPS](https://github.com/getsops/sops) - Simple and flexible tool for managing secrets.
- [Infisical](https://github.com/Infisical/infisical) - Open-source secret management platform.
- [OpenBao](https://github.com/openbao/openbao) - Open-source secrets management and encryption (Vault fork).

## Web security & testing

- [OWASP ZAP](https://github.com/zaproxy/zaproxy) - The world's most widely used web app scanner.
- [Nuclei](https://github.com/projectdiscovery/nuclei) - Fast, template-based vulnerability scanner.
- [sqlmap](https://github.com/sqlmapproject/sqlmap) - Automatic SQL injection and database takeover tool.
- [Nmap](https://github.com/nmap/nmap) - The network mapper.
- [mitmproxy](https://github.com/mitmproxy/mitmproxy) - Interactive TLS-capable intercepting HTTP proxy.

## Identity & auth

- [Keycloak](https://github.com/keycloak/keycloak) - Open-source identity and access management.
- [Authentik](https://github.com/goauthentik/authentik) - Flexible, open-source identity provider.
- [Ory Kratos](https://github.com/ory/kratos) - Cloud-native identity and user management.
- [Better Auth](https://github.com/better-auth/better-auth) - Comprehensive authentication framework for TypeScript.

## Learn security

- [OWASP Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries) - Concise, high-value security guidance for developers.
- [OWASP Top 10](https://github.com/OWASP/Top10) - The standard awareness document for web application security.
- [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Useful payloads and bypasses for web application security.
- [Awesome Security](https://github.com/sbilly/awesome-security) - Collection of awesome software, libraries, documents and resources about security.
- [Awesome Hacking](https://github.com/Hack-with-Github/Awesome-Hacking) - Curated lists for hackers, pentesters and security researchers.
- [Hacker Laws](https://github.com/dwmkerr/hacker-laws) - Laws, theories, principles and patterns useful to developers.
