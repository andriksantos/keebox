# AI & LLM Tools

Curated open-source tools, frameworks, local model runtimes and learning resources for building with artificial intelligence and large language models (LLMs).

!!! tip "41 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Run models locally

- [Ollama](https://github.com/ollama/ollama) - Get up and running with Llama, Gemma, Qwen and other open models on your own machine.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) - LLM inference in C/C++ that runs on CPUs, Apple Silicon and GPUs.
- [vLLM](https://github.com/vllm-project/vllm) - High-throughput, memory-efficient inference and serving engine for LLMs.
- [Open WebUI](https://github.com/open-webui/open-webui) - Self-hosted, ChatGPT-style web interface for Ollama and OpenAI-compatible APIs.
- [LocalAI](https://github.com/mudler/LocalAI) - Drop-in, OpenAI-compatible API that runs models on consumer hardware.
- [Jan](https://github.com/janhq/jan) - Open-source desktop app that runs LLMs 100% offline.

## Frameworks & SDKs

- [LangChain](https://github.com/langchain-ai/langchain) - Framework for building context-aware LLM applications and agents.
- [LlamaIndex](https://github.com/run-llama/llama_index) - Data framework to connect your own data to LLMs (RAG).
- [Hugging Face Transformers](https://github.com/huggingface/transformers) - Thousands of pretrained models for text, vision and audio.
- [LiteLLM](https://github.com/BerriAI/litellm) - Call 100+ LLM APIs using the OpenAI format, with a proxy server and cost tracking.
- [Anthropic Python SDK](https://github.com/anthropics/anthropic-sdk-python) - Official Python library for the Claude API.
- [OpenAI Python SDK](https://github.com/openai/openai-python) - Official Python library for the OpenAI API.
- [Vercel AI SDK](https://github.com/vercel/ai) - TypeScript toolkit for building AI-powered web apps and agents.
- [DSPy](https://github.com/stanfordnlp/dspy) - Programming, not prompting, language models.

## Agents & MCP

- [Model Context Protocol servers](https://github.com/modelcontextprotocol/servers) - Reference servers that connect AI assistants to tools and data.
- [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers) - Community collection of Model Context Protocol servers.
- [CrewAI](https://github.com/crewAIInc/crewAI) - Framework for orchestrating role-playing, autonomous AI agents.
- [AutoGen](https://github.com/microsoft/autogen) - Microsoft framework for multi-agent AI applications.
- [LangGraph](https://github.com/langchain-ai/langgraph) - Build resilient, stateful agents as graphs.
- [Awesome AI Agents](https://github.com/e2b-dev/awesome-ai-agents) - List of AI autonomous agents and frameworks.

## Coding assistants

- [Aider](https://github.com/Aider-AI/aider) - AI pair programming in your terminal.
- [Continue](https://github.com/continuedev/continue) - Open-source AI code assistant for VS Code and JetBrains.
- [Cline](https://github.com/cline/cline) - Autonomous coding agent inside your IDE.
- [Tabby](https://github.com/TabbyML/tabby) - Self-hosted AI coding assistant.

## Vector databases & RAG

- [Chroma](https://github.com/chroma-core/chroma) - Open-source embedding database for AI apps.
- [Qdrant](https://github.com/qdrant/qdrant) - High-performance vector search engine written in Rust.
- [Milvus](https://github.com/milvus-io/milvus) - Cloud-native vector database built for scalable similarity search.
- [pgvector](https://github.com/pgvector/pgvector) - Vector similarity search for PostgreSQL.
- [Weaviate](https://github.com/weaviate/weaviate) - Open-source vector database with hybrid search.

## Image, audio & demos

- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) - Node-based interface for diffusion models.
- [Stable Diffusion web UI](https://github.com/AUTOMATIC1111/stable-diffusion-webui) - Browser interface for Stable Diffusion.
- [Whisper](https://github.com/openai/whisper) - Robust speech recognition via large-scale weak supervision.
- [Gradio](https://github.com/gradio-app/gradio) - Build and share ML demos and web apps in Python.
- [Streamlit](https://github.com/streamlit/streamlit) - Turn data scripts into shareable web apps in minutes.
