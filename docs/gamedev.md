# Game Development

Curated open-source game engines, frameworks, tools, free assets and learning resources for making games.

!!! tip "19 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Engines

- [Godot](https://github.com/godotengine/godot) - Multi-platform 2D and 3D game engine.
- [Bevy](https://github.com/bevyengine/bevy) - Data-driven game engine built in Rust.
- [O3DE](https://github.com/o3de/o3de) - Open 3D Engine for AAA-quality games and simulations.
- [Defold](https://github.com/defold/defold) - Completely free to use game engine for cross-platform games.
- [Stride](https://github.com/stride3d/stride) - Open-source C# game engine.

## Frameworks

- [Phaser](https://github.com/phaserjs/phaser) - Fun, fast and free HTML5 game framework.
- [LÖVE](https://github.com/love2d/love) - 2D game framework for Lua.
- [raylib](https://github.com/raysan5/raylib) - Simple and easy-to-use library to enjoy videogames programming.
- [MonoGame](https://github.com/MonoGame/MonoGame) - One framework for creating powerful cross-platform games.
- [PixiJS](https://github.com/pixijs/pixijs) - The HTML5 creation engine for 2D WebGL graphics.
- [Babylon.js](https://github.com/BabylonJS/Babylon.js) - Powerful, beautiful, simple and open game and rendering engine.

## Tools

- [Blender](https://github.com/blender/blender) - Free and open-source 3D creation suite.
- [LDtk](https://github.com/deepnight/ldtk) - Modern 2D level editor.
- [Tiled](https://github.com/mapeditor/tiled) - Flexible level editor.
- [Aseprite](https://github.com/aseprite/aseprite) - Animated sprite editor and pixel art tool.

## Learn & assets

- [Awesome Game Development](https://github.com/Calinou/awesome-gamedev) - Free and open-source software and assets for game development.
- [Awesome Godot](https://github.com/Calinou/awesome-godot) - Curated list of free and open-source Godot content.
- [Game Programming Patterns (code)](https://github.com/munificent/game-programming-patterns) - Source for the Game Programming Patterns book.
- [Magictools](https://github.com/ellisonleao/magictools) - Game development resources to make magic happen.
