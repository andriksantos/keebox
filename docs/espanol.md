# Recursos en español

Recursos gratuitos para aprender programación en español: libros, cursos, retos, comunidades y listas curadas para desarrolladores hispanohablantes.

!!! tip "21 recursos seleccionados"
    Todos los enlaces se revisaron en noviembre de 2026. ¿Conoces un recurso en español que falte? [Sugiérelo en GitHub](https://github.com/andriksantos/keebox/issues/new) o lee la [guía de contribución](contributing.md).

## Libros y cursos gratis

- [Libros de programación gratis](https://github.com/midudev/libros-programacion-gratis) - Lista de libros sobre programación en español y gratis.
- [Biblioteca gratis en español](https://github.com/rosepac/biblioteca-espanol-gratis) - Cursos y libros gratis de programación, diseño y tecnología.
- [Libros de GitBook en español](https://github.com/rosepac/gitbook-biblioteca-impresionante-en-espanol) - Recopilación de libros de programación en español en GitBook.
- [Free Programming Books](https://github.com/EbookFoundation/free-programming-books) - Libros gratuitos en muchos idiomas, con sección en español.
- [Curso Python Web (MoureDev)](https://github.com/mouredev/python-web) - Curso para aprender desarrollo frontend web con Python desde cero.
- [Hello Python (MoureDev)](https://github.com/mouredev/hello-python) - Curso para aprender Python desde cero.
- [Hello Git (MoureDev)](https://github.com/mouredev/hello-git) - Curso para aprender Git y GitHub desde cero.
