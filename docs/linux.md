# Linux & Terminal

Curated Linux, shell and command-line tools, dotfiles and learning resources to become faster and more productive in the terminal.

!!! tip "25 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Shells & prompts

- [Oh My Zsh](https://github.com/ohmyzsh/ohmyzsh) - Framework for managing your Zsh configuration.
- [fish shell](https://github.com/fish-shell/fish-shell) - The user-friendly command line shell.
- [Nushell](https://github.com/nushell/nushell) - A new type of shell with structured data.
- [Powerlevel10k](https://github.com/romkatv/powerlevel10k) - Fast and flexible Zsh theme.
- [tmux](https://github.com/tmux/tmux) - Terminal multiplexer.
- [Zellij](https://github.com/zellij-org/zellij) - Terminal workspace with batteries included.

## Modern CLI tools

- [fzf](https://github.com/junegunn/fzf) - Command-line fuzzy finder.
- [zoxide](https://github.com/ajeetdsouza/zoxide) - A smarter cd command.
- [eza](https://github.com/eza-community/eza) - Modern, maintained replacement for ls.
- [jq](https://github.com/jqlang/jq) - Command-line JSON processor.
- [btop](https://github.com/aristocratos/btop) - Resource monitor with a beautiful interface.
- [tldr pages](https://github.com/tldr-pages/tldr) - Simplified, community-driven man pages.
- [HTTPie](https://github.com/httpie/cli) - Modern, user-friendly command-line HTTP client.
- [Neovim](https://github.com/neovim/neovim) - Vim-fork focused on extensibility and usability.
- [Atuin](https://github.com/atuinsh/atuin) - Magical shell history.

## Dotfiles & setup

- [chezmoi](https://github.com/twpayne/chezmoi) - Manage your dotfiles across multiple machines, securely.
- [GNU Stow](https://github.com/aspiers/stow) - Symlink farm manager for dotfiles.
- [Homebrew](https://github.com/Homebrew/brew) - The missing package manager for macOS (and Linux).
- [Awesome dotfiles](https://github.com/webpro/awesome-dotfiles) - Curated list of dotfiles resources.

## Learn

- [The Art of Command Line](https://github.com/jlevy/the-art-of-command-line) - Master the command line, in one page.
- [Linux Command Library](https://github.com/SimonSchubert/LinuxCommandLibrary) - Thousands of Linux command manuals and tips.
- [Bash Guide](https://github.com/Idnan/bash-guide) - A guide to learn bash.
- [Awesome Shell](https://github.com/alebcay/awesome-shell) - Command-line frameworks, toolkits, guides and gizmos.
- [Awesome Linux](https://github.com/inputsh/awesome-linux) - List of awesome projects and resources for Linux.
- [Linux Insides](https://github.com/0xAX/linux-insides) - A little bit about the Linux kernel.
