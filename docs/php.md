# PHP

Curated PHP frameworks, CMSs, libraries, tools and learning resources for building websites, APIs and e-commerce.

!!! tip "22 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Frameworks

- [Laravel](https://github.com/laravel/laravel) - The PHP framework for web artisans.
- [Symfony](https://github.com/symfony/symfony) - Set of reusable PHP components and a web framework.
- [CodeIgniter 4](https://github.com/codeigniter4/CodeIgniter4) - Powerful PHP framework with a very small footprint.
- [Slim](https://github.com/slimphp/Slim) - PHP micro framework for web applications and APIs.
- [Livewire](https://github.com/livewire/livewire) - Full-stack framework for Laravel to build dynamic UIs.
- [Filament](https://github.com/filamentphp/filament) - Accelerated Laravel development framework: admin panels and apps.

## CMS & e-commerce

- [WordPress](https://github.com/WordPress/WordPress) - The open-source software that powers a large share of the web.
- [WooCommerce](https://github.com/woocommerce/woocommerce) - Customizable, open-source e-commerce platform built on WordPress.
- [Drupal](https://github.com/drupal/drupal) - Flexible open-source CMS.
- [Statamic](https://github.com/statamic/cms) - Flat-first Laravel and Git powered CMS.
- [Magento Open Source](https://github.com/magento/magento2) - Open-source e-commerce platform.

## Libraries & tools

- [Composer](https://github.com/composer/composer) - Dependency manager for PHP.
- [Guzzle](https://github.com/guzzle/guzzle) - Extensible PHP HTTP client.
- [Monolog](https://github.com/Seldaek/monolog) - Sends your logs to files, sockets, inboxes and more.
- [PHPUnit](https://github.com/sebastianbergmann/phpunit) - The PHP unit testing framework.
- [Pest](https://github.com/pestphp/pest) - Elegant PHP testing framework.
- [PHPStan](https://github.com/phpstan/phpstan) - PHP static analysis tool.
- [Laravel Pint](https://github.com/laravel/pint) - Opinionated PHP code style fixer.

## Learn

- [Awesome PHP](https://github.com/ziadoz/awesome-php) - Curated list of amazingly awesome PHP libraries and resources.
- [Awesome Laravel](https://github.com/chiraggude/awesome-laravel) - Curated list of bookmarks, packages, tutorials and videos for Laravel.
- [Clean Code PHP](https://github.com/piotrplenik/clean-code-php) - Clean Code concepts adapted for PHP.
- [DesignPatternsPHP](https://github.com/DesignPatternsPHP/DesignPatternsPHP) - Sample code for design patterns in PHP.
