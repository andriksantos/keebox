# Cloud & Free Tiers

Curated cloud tools, CLIs, serverless frameworks and lists of free tiers to deploy and host your projects on AWS, Google Cloud, Azure, Cloudflare and more.

!!! tip "19 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Free tiers & credits

- [Free for Dev](https://github.com/ripienaar/free-for-dev) - Huge list of SaaS, PaaS and IaaS offerings with free tiers.
- [Serverless Cloud SQL Comparison](https://github.com/hbmartin/comparison-serverless-cloud-sql-databases) - Comparison of serverless cloud SQL database providers and their free tiers.
- [Awesome Free Hosting (awesome-selfhosted)](https://github.com/awesome-selfhosted/awesome-selfhosted) - Self-host alternatives to popular cloud services.

## Provider CLIs & SDKs

- [AWS CLI](https://github.com/aws/aws-cli) - Universal command line interface for Amazon Web Services.
- [AWS CDK](https://github.com/aws/aws-cdk) - Define cloud infrastructure using familiar programming languages.
- [Azure CLI](https://github.com/Azure/azure-cli) - Command-line tools for Azure.
- [Google Cloud SDK samples](https://github.com/GoogleCloudPlatform/python-docs-samples) - Code samples for Google Cloud in Python.
- [Wrangler (Cloudflare Workers)](https://github.com/cloudflare/workers-sdk) - Build and deploy Cloudflare Workers.
- [Vercel CLI](https://github.com/vercel/vercel) - Develop, preview and ship on Vercel.
- [Netlify CLI](https://github.com/netlify/cli) - Netlify command line tool.

## Serverless & edge

- [Serverless Framework](https://github.com/serverless/serverless) - Build applications on AWS Lambda and other serverless platforms.
- [SST](https://github.com/anomalyco/sst) - Build full-stack apps on your own infrastructure.
- [Hono](https://github.com/honojs/hono) - Web framework built on Web Standards for the edge.
- [OpenFaaS](https://github.com/openfaas/faas) - Serverless functions made simple.
- [LocalStack](https://github.com/localstack/localstack) - Fully functional local AWS cloud stack.
