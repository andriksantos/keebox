# IoT & Hardware

Curated IoT, home automation and hardware resources: Arduino, ESP32, Raspberry Pi, MQTT and smart home platforms.

!!! tip "19 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Platforms & firmware

- [Arduino IDE](https://github.com/arduino/arduino-ide) - Open-source IDE for Arduino boards.
- [PlatformIO Core](https://github.com/platformio/platformio-core) - Professional collaborative platform for embedded development.
- [ESP-IDF](https://github.com/espressif/esp-idf) - Espressif IoT Development Framework for ESP32.
- [Arduino core for ESP32](https://github.com/espressif/arduino-esp32) - Arduino support for ESP32 chips.
- [MicroPython](https://github.com/micropython/micropython) - Lean and efficient Python for microcontrollers.
- [Zephyr RTOS](https://github.com/zephyrproject-rtos/zephyr) - Scalable real-time operating system for connected devices.

## Smart home

- [Home Assistant](https://github.com/home-assistant/core) - Open-source home automation that puts local control first.
- [ESPHome](https://github.com/esphome/esphome) - Control your ESP8266/ESP32 with simple YAML files.
- [Tasmota](https://github.com/arendst/Tasmota) - Alternative firmware for ESP8266/ESP32 smart devices.
- [Zigbee2MQTT](https://github.com/Koenkk/zigbee2mqtt) - Use Zigbee devices without the vendor bridge.
- [Node-RED](https://github.com/node-red/node-red) - Low-code programming for event-driven applications.

## Messaging & data

- [Eclipse Mosquitto](https://github.com/eclipse-mosquitto/mosquitto) - Open-source MQTT broker.
- [EMQX](https://github.com/emqx/emqx) - Scalable MQTT platform for IoT.
- [ThingsBoard](https://github.com/thingsboard/thingsboard) - Open-source IoT platform for data collection and visualization.
