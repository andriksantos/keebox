# Rust

Curated Rust frameworks, crates, tools and learning resources for building fast, safe systems, web services and CLIs.

!!! tip "23 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Web & async

- [Tokio](https://github.com/tokio-rs/tokio) - Runtime for writing reliable asynchronous applications.
- [Axum](https://github.com/tokio-rs/axum) - Ergonomic and modular web framework built on Tokio.
- [Actix Web](https://github.com/actix/actix-web) - Powerful, pragmatic and extremely fast web framework.
- [Leptos](https://github.com/leptos-rs/leptos) - Full-stack, fine-grained reactive web framework.
- [Dioxus](https://github.com/DioxusLabs/dioxus) - Fullstack app framework for web, desktop and mobile.

## Crates

- [Serde](https://github.com/serde-rs/serde) - Serialization framework for Rust.
- [Clap](https://github.com/clap-rs/clap) - Full-featured command line argument parser.
- [SQLx](https://github.com/transact-rs/sqlx) - Async SQL toolkit with compile-time checked queries.
- [Diesel](https://github.com/diesel-rs/diesel) - Safe, extensible ORM and query builder.
- [Rayon](https://github.com/rayon-rs/rayon) - Data parallelism library.
- [Ratatui](https://github.com/ratatui/ratatui) - Library to build rich terminal user interfaces.
- [Bevy](https://github.com/bevyengine/bevy) - Refreshingly simple data-driven game engine.

## Tools built with Rust

- [ripgrep](https://github.com/BurntSushi/ripgrep) - Recursively search directories for a regex pattern.
- [fd](https://github.com/sharkdp/fd) - Simple, fast and user-friendly alternative to find.
- [bat](https://github.com/sharkdp/bat) - A cat clone with wings.
- [Zed](https://github.com/zed-industries/zed) - High-performance, multiplayer code editor.
- [Alacritty](https://github.com/alacritty/alacritty) - Fast, cross-platform, OpenGL terminal emulator.
- [Starship](https://github.com/starship/starship) - Minimal, blazing-fast and customizable prompt for any shell.

## Learn Rust

- [The Rust Book](https://github.com/rust-lang/book) - The Rust Programming Language book.
- [Rustlings](https://github.com/rust-lang/rustlings) - Small exercises to get you used to reading and writing Rust.
- [Rust by Example](https://github.com/rust-lang/rust-by-example) - Learn Rust with examples.
- [Comprehensive Rust](https://github.com/google/comprehensive-rust) - Rust course used by the Android team at Google.
- [Awesome Rust](https://github.com/rust-unofficial/awesome-rust) - Curated list of Rust code and resources.
