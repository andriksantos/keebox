# DevOps & Self-hosting

Curated DevOps tools for containers, infrastructure as code, CI/CD, monitoring and self-hosting your own services.

!!! tip "34 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Containers & orchestration

- [Docker Compose](https://github.com/docker/compose) - Define and run multi-container applications.
- [Kubernetes](https://github.com/kubernetes/kubernetes) - Production-grade container scheduling and management.
- [k3s](https://github.com/k3s-io/k3s) - Lightweight Kubernetes.
- [kind](https://github.com/kubernetes-sigs/kind) - Run local Kubernetes clusters using Docker.
- [Helm](https://github.com/helm/helm) - The Kubernetes package manager.
- [Podman](https://github.com/podman-container-tools/podman) - Daemonless tool for managing containers and pods.

## Infrastructure as code

- [Terraform](https://github.com/hashicorp/terraform) - Safely and predictably create, change and improve infrastructure.
- [OpenTofu](https://github.com/opentofu/opentofu) - Open-source, community-driven fork of Terraform.
- [Ansible](https://github.com/ansible/ansible) - Simple, agentless IT automation.
- [Pulumi](https://github.com/pulumi/pulumi) - Infrastructure as code in any programming language.

## CI/CD & deployment

- [Argo CD](https://github.com/argoproj/argo-cd) - Declarative, GitOps continuous delivery for Kubernetes.
- [act](https://github.com/nektos/act) - Run your GitHub Actions locally.
- [Coolify](https://github.com/coollabsio/coolify) - Open-source, self-hostable alternative to Heroku, Netlify and Vercel.
- [Dokku](https://github.com/dokku/dokku) - Docker-powered mini-Heroku.
- [Kamal](https://github.com/basecamp/kamal) - Deploy web apps anywhere, from bare metal to cloud VMs.

## Web servers & networking

- [Caddy](https://github.com/caddyserver/caddy) - Fast web server with automatic HTTPS.
- [Traefik](https://github.com/traefik/traefik) - Cloud-native application proxy.
- [Nginx Proxy Manager](https://github.com/NginxProxyManager/nginx-proxy-manager) - Manage Nginx proxy hosts with a simple web interface.
- [WireGuard tools](https://github.com/WireGuard/wireguard-tools) - Tools for configuring WireGuard VPN tunnels.

## Monitoring & observability

- [Prometheus](https://github.com/prometheus/prometheus) - Monitoring system and time series database.
- [Grafana](https://github.com/grafana/grafana) - Observability and data visualization platform.
- [Uptime Kuma](https://github.com/louislam/uptime-kuma) - Fancy self-hosted monitoring tool.
- [Netdata](https://github.com/netdata/netdata) - Real-time, high-resolution infrastructure monitoring.
- [OpenTelemetry Collector](https://github.com/open-telemetry/opentelemetry-collector) - Vendor-agnostic telemetry pipeline.

## Developer productivity

- [lazygit](https://github.com/jesseduffield/lazygit) - Simple terminal UI for git commands.
- [lazydocker](https://github.com/jesseduffield/lazydocker) - Terminal UI for Docker and Docker Compose.
- [k9s](https://github.com/derailed/k9s) - Terminal UI to manage Kubernetes clusters.
- [Portainer](https://github.com/portainer/portainer) - Container management UI for Docker and Kubernetes.
- [MinIO](https://github.com/minio/minio) - High-performance, S3-compatible object storage.
