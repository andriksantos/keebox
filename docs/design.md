# Design & UI Assets

Curated free icons, fonts, illustrations, design tools and UI resources for developers who want great-looking products.

!!! tip "26 hand-picked resources"
    Every link on this page was checked in November 2026. Know a great project that is missing? [Suggest it on GitHub](https://github.com/andriksantos/keebox/issues/new) or read the [contribution guide](contributing.md).

## Icons

- [Lucide](https://github.com/lucide-icons/lucide) - Beautiful and consistent open-source icon toolkit.
- [Tabler Icons](https://github.com/tabler/tabler-icons) - 5,000+ free MIT-licensed SVG icons.
- [Heroicons](https://github.com/tailwindlabs/heroicons) - Hand-crafted SVG icons by the makers of Tailwind CSS.
- [Font Awesome](https://github.com/FortAwesome/Font-Awesome) - The iconic SVG, font and CSS toolkit.
- [Simple Icons](https://github.com/simple-icons/simple-icons) - SVG icons for popular brands.
- [Iconify](https://github.com/iconify/iconify) - Universal icon framework with 200,000+ icons.

## Fonts

- [Inter](https://github.com/rsms/inter) - Typeface carefully crafted for computer screens.
- [Geist](https://github.com/vercel/geist-font) - Font family by Vercel for developers and designers.
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) - Typeface made for developers.
- [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) - Iconic font aggregator, collection and patcher.
- [Fontsource](https://github.com/fontsource/fontsource) - Self-host open-source fonts in neatly bundled npm packages.

## Design tools

- [Penpot](https://github.com/penpot/penpot) - Open-source design and prototyping platform.
- [Excalidraw](https://github.com/excalidraw/excalidraw) - Virtual whiteboard for sketching hand-drawn-like diagrams.
- [tldraw](https://github.com/tldraw/tldraw) - Infinite canvas SDK and whiteboard.
- [draw.io](https://github.com/jgraph/drawio) - Diagramming and whiteboarding application.
- [Storybook](https://github.com/storybookjs/storybook) - Workshop for building UI components and pages in isolation.

## Animation & visuals

- [Lottie Web](https://github.com/airbnb/lottie-web) - Render After Effects animations natively on the web.
- [Motion](https://github.com/motiondivision/motion) - Animation library for JavaScript and React.
- [GSAP](https://github.com/greensock/GSAP) - Professional-grade JavaScript animation library.
- [Three.js](https://github.com/mrdoob/three.js) - JavaScript 3D library.
- [Chart.js](https://github.com/chartjs/Chart.js) - Simple HTML5 charts using the canvas element.
- [Apache ECharts](https://github.com/apache/echarts) - Powerful, interactive charting and visualization library.
