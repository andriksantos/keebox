## ✨ Why KEEBOX LIST™?

|  |  |
| --- | --- |
| 🎯 **Curated, not scraped** | Every resource is chosen by developers and grouped by what you are trying to build. |
| 🔄 **Always up to date** | Links are checked automatically every month — moved projects are updated, dead ones removed. |
| ⚡ **Instant search** | Press <kbd>/</kbd> on the site to search all 7,000+ resources in milliseconds. |
| 🆓 **Free & open source** | No sign-up, no paywall, no ads. MIT licensed. |

## 🤝 Contributing

Found a great resource that's missing? Contributions are always welcome! 😎

1. Read the [contribution guidelines](docs/contributing.md) and the [code of conduct](docs/code-of-conduct.md).
2. Add **one link per pull request** using this format:
   `- [Project name](https://example.com) - A short description that ends with a period.`
3. Open a pull request explaining why the resource is awesome.

Not a coder? [Open an issue](https://github.com/andriksantos/keebox/issues/new) with your suggestion.

## 🛠️ Run the site locally

Built with [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export NO_MKDOCS_2_WARNING=1
mkdocs serve --livereload    # → http://127.0.0.1:8000/keebox/
```

Every push to `master` is published automatically to the `gh-pages` branch by the [official Material for MkDocs workflow](https://squidfunk.github.io/mkdocs-material/publishing-your-site/) in `.github/workflows/ci.yml`.
