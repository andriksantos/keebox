# Welcome to **KEEBOX LIST™** | Developer Resources

KEEBOX LIST™ is a free, curated directory of **6,500+ hand-picked developer resources** — your centralized reference point to quickly find tools, libraries and guides relevant to your work.

## What will you find here?

| Section | What's inside |
| --- | --- |
| [AI & LLM Tools](https://andriksantos.com/keebox/ai/) | Local model runtimes, agents, MCP servers, RAG and vector databases |
| [Python](https://andriksantos.com/keebox/python/) | Modern tooling, web frameworks, data science and libraries |
| [Web Development](https://andriksantos.com/keebox/web/) | React, Vue, Svelte, Next.js, Tailwind, testing and build tools |

## Why use KEEBOX LIST™?

With so many resources online, it can be hard to find the most relevant and reliable ones. KEEBOX LIST™ is curated and constantly evolving, created by developers for developers, to save you time and put the right tools in one place. Links are checked automatically every month.

## Run the site locally

The site is built with [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve          # http://127.0.0.1:8000
mkdocs build --strict # production build into ./site
```

Every push to `master` is published to the `gh-pages` branch by the [official Material for MkDocs workflow](https://squidfunk.github.io/mkdocs-material/publishing-your-site/) in `.github/workflows/ci.yml`.
